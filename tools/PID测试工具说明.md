# PID 阶跃响应测试工具

自动化测试 STS3215 舵机 PID 控制效果的脚本。通过 STM32 控制台（USART6）发送阶跃运动指令并密集采集实际角度，自动分析响应特性并绘图。

## ⚠️ 最关键的一步：先关闭你的串口助手

**运行脚本前，必须把当前打开着的串口助手（XCOM / SSCOM / SSCOM32 / 其他串口调试工具）完全关闭并退出。**

原因：同一个串口（COM8）**同时只能被一个程序打开**。你的串口助手只要开着，就会把 COM8 占死，脚本会报"串口被占用 / 拒绝访问"而无法运行。

> 判断方法：如果脚本报 `PermissionError` / `could not open port` / `拒绝访问`，99% 是串口助手没关。关掉它，重新运行即可。

```bash
C:/Users/Administrator/.workbuddy/binaries/python/envs/default/Scripts/python.exe \
    tools/pid_step_test.py --port COM8 --joint 2 \
    --start 165 --end 200 --p 32 --i 4 --d 12
```

## 参数说明

| 参数 | 默认 | 说明 |
|------|------|------|
| `--port` | COM8 | 串口号（设备管理器中确认） |
| `--baud` | 115200 | 波特率 |
| `--joint` | 2 | **物理关节号 1~6**（1=J1, 2=J2, ..., 6=J6） |
| `--start` | 165 | 阶跃起始角度（度，先运动到位） |
| `--end` | 200 | 阶跃目标角度（度） |
| `--p` / `--i` / `--d` | 不改 | 设置该关节 PID 增益 |
| `--samples` | 200 | 采样点数（每点 20ms，200 点约 4s） |
| `--interval_s` | 0.02 | 采样间隔（秒） |
| `--save` | 1 | 1=完成后写 F 保存到 Flash |
| `--out` | pid_step | 输出文件前缀 |

## ⚠️ 固件关节编号机制（重要）

你的固件**两类命令的关节编号不一致**（这是个固件坑，脚本已自动处理）：

| 命令 | 编号语义 | 例 |
|------|----------|-----|
| 控制命令 `a` / `p` / `t` | **0-based index** | `a 0`=J1, `a 1`=J2, `a 2`=J3 |
| PID 命令 `N` / `K` / `I` / `D` | **物理编号** | `N 1`=J1, `N 2`=J2 |

所以**手动操作时**要注意：要让 J2 动用 `a 1`，但设 J2 的 PID 用 `N 2`。
**本脚本已自动处理**：`--joint 2` 表示物理 J2，内部发送 `a 1`（动 J2）+ `N 2`（设 J2 PID）+ 用 `pv` 采集 J2 的角度。

> 如果你之前用的是 `--joint 2` 但看到 J3 在动，那是旧版本脚本把编号直接透传导致的 bug，已修复。

## 典型使用流程

```bash
# 测试 J2 在 P=32/D=12/I=4 下的阶跃响应
python pid_step_test.py --port COM8 --joint 2 --start 165 --end 200 --p 32 --i 4 --d 12

# 测试 P=48（更大刚度）看超调是否变大
python pid_step_test.py --port COM8 --joint 2 --start 165 --end 200 --p 48 --i 4 --d 12

# 测试只加 D 阻尼抑制振荡
python pid_step_test.py --port COM8 --joint 2 --start 165 --end 200 --p 32 --i 4 --d 20
```

## 分析指标

| 指标 | 含义 | 良好值参考 |
|------|------|-----------|
| 稳态误差 ess | 到位后与目标偏差 | 越小越好（抗重力靠 I） |
| 超调量 OS% | 越过目标的最大比例 | <10%（过大说明 P 太强/D 不足） |
| 上升时间 tr | 10%→90% 时间 | 越小响应越快 |
| 峰值时间 tp | 首次最大值时间 | — |
| 稳定时间 ts | 进入 ±2% 窗口 | 越小越好 |

## 调参建议

- **过冲振荡** → 增大 D（阻尼）、或减小 P
- **到位慢/抗重力差** → 增大 P（刚度）、或增大 I（消稳态误差）
- **稳态抖动** → 减小 I、增大 D
- 每次调参后重启串口测试，对比超调和稳定时间变化

## 注意事项

1. 测试前确认机械臂已 `i` 初始化、`t a 1` 使能扭矩
2. 起始/目标角度在关节限位范围内，避免撞到限位开关
3. 测试时手臂尽量不受额外负载，保证结果可比
4. 如果 `p J` 返回 None，检查串口是否被其他程序占用、波特率是否正确
