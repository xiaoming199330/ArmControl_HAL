# 六轴机械臂上位机开发包（ArmControl_HAL Host SDK Package）

> **这份包是给"另一个 AI / 另一位工程师"看的**，目的是让他在**不理解 STM32 固件源码**的前提下，
> 也能准确、快速地做出一个**好用且无 bug** 的上位机软件（PC / Web / Electron / Qt / WPF 均可）。
>
> 生成日期：2026-09-11（对应 `Core/Src/main.c` 最后修改日）
> 对应固件：`ArmControl_HAL`（STM32F407ZGT6 + 飞特 Feetech STS3215 ×6），源码树见文末"源工程位置"。

## 0. 30 秒摘要（先看这个）

| 项 | 值 |
|---|---|
| 被控对象 | 6 自由度串联机械臂（SO-ARM101 构型） |
| 主控 | STM32F407ZGT6 @168 MHz，裸机 HAL（无 RTOS） |
| 执行器 | Feetech **STS3215**（12V 30KG），**SCS 半双工串行总线**，1 Mbps |
| 上位机接口 | **串口 USART6，115200 8N1，无流控**（USB 转串口 → COM 口） |
| 接口形态 | **① ASCII 文本命令（主体） + ② 二进制协议（同一串口，0xAA 0x55 帧头）** |
| ⚠ 行尾 | **必须 CRLF（`0x0D 0x0A`）**，否则命令**永不执行**（最高频的"发了没响应"原因） |
| ⚠ 角度单位 | 两套：**舵机度 0~360°** 与 **关节角（相对 Home，可正可负，度）**，**不可混用**。⚠ **`a`/`m`/`B`/`q`/`L` 的入参是舵机度**（`m` 硬钳 0~300）；关节角只出现在 `f`/`p` 的输出侧与 `g` 的 pitch |
| ⚠ 结果判定 | **三态**：成功 / 🟡被限位钳制 / 🔴被拒绝。只看"有没有报错"会把钳制和假成功判成成功 |
| ⚠ 关节号 | 两套：**单轴命令用 0~5**，**PID 命令用 1~6** |
| 坐标系 | X=前，Y=左，Z=上；原点=**桌面上的 J1 轴心**；位置单位 **mm** |
| 机械臂"零点" | 官方 Home 姿态（上臂近竖直 +13.97°、前臂水平 87.79°），**出厂 raw=2048**，可现场校准漂移 |

## 3. 四条铁律（先记住，后面文档再展开）

1. **每条命令必须以 `\r\n` 结尾**，否则固件不认为"行结束"，命令不会被执行。
2. **不要用"目标值/期望值"顶替"读失败"的反馈**。固件对读位置失败的处理是**拒绝运动**，不是兜底；上位机也必须把"读不到"如实显示成错误，绝不能用上次的值糊过去。
3. **位姿/路点不要写死舵机度**。现场零点会随校准漂移（可能漂移上百舵机度）。一律用**关节角（相对 Home）** 或 **XYZ 坐标**；注意 `q` 存的路点是**舵机度**（与其它"不要写死"的场合区分：**存之前**用关节角决定姿态，**存下来**的字节是舵机度）。
4. **结果判定必须分三态**：成功 / 🟡被钳制 / 🔴被拒绝。固件存在两类"看起来成功"的回包——`Unknown command …` 这类错误串若不收录进失败关键词就会**假成功**；`a`/`q`/`B` 被限位钳制时**仍返回成功**（`m` 的 0~300 钳制连打印都没有）。SDK 已提供 `clamps()` 与修正后的 `classify()`，移植时必须照抄关键词表。
