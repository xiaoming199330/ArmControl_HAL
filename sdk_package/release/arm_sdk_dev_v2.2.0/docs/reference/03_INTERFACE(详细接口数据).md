## 1. 通信层（必读）

### 1.1 串口参数

| 项 | 值 |
|---|---|
| 物理口 | 板载 **USART6**（STM32 侧 PC6=TX / PC7=RX），经 USB 转串口到 PC |
| 波特率 | **115200** |
| 数据位 / 校验 / 停止位 | **8 / None / 1（8N1）** |
| 流控 | **无**（无 RTS/CTS、无 XON/XOFF、无 DTR 握手） |
| 字符集 | **ASCII**（中文/全角不识别） |
| 建议 | 打开串口后**先清空收发缓冲**，再发第一条命令 |

### 1.2 ⚠ 行尾类型（最高优先级）

固件判行（`main.c` → `Console_TryReadLine()`）：

```c
if (ch == '\r' || ch == '\n') {        /* CR 或 LF 都算"一行结束" */
    if (console_rx_len == 0) return 0; /* 空行忽略 */
    console_rx[console_rx_len] = '\0';
    ...                                /* 到这里命令才会被执行 */
    return len;
}
```

| 行尾 | 字节 | 固件行为 |
|---|---|---|
| **CRLF** | `0D 0A` | ✅ 执行（**统一用这个**） |
| LF | `0A` | ✅ 执行 |
| CR | `0D` | ✅ 执行 |
| **无行尾** | — | ❌ **永不执行** → 现象："下发了没响应" |
| 空行 | — | 忽略，不报错 |

**强制要求**
1. 任何命令末尾**必须**加 `\r` / `\n` / `\r\n`；**上位机统一用 `\r\n`**。
2. **不得**发送"命令本体 + 无终止符"。
3. `\r\n` 连发**不会**重复执行（`\r` 结束一行，`\n` 被当空行丢弃）。
4. 把它封装进 `send_command()`，让业务层无法漏掉。

### 1.3 命令解析规则

| 规则 | 值 | 备注 |
|---|---|---|
| 单行最大长度 | **128 字节缓冲 / 127 字符** | `console_rx[128]`，超出丢弃 |
| 分词 | **空格 / Tab** | **不认逗号、分号、引号** |
| 参数上限 | **16 个 token** | `char* tokens[16]`，多余忽略 |
| 大小写 | **严格区分** | `m`≠`M`、`p`≠`P`、`s`≠`S`、`t`≠`T`、`b`≠`B`、`c`≠`C`、`d`≠`D`、`q`≠`Q` |
| 浮点 | `atof`（角度/坐标支持小数） | |
| 整数 | `atoi` / `strtol`（关节号/枚举） | |
| 退格 | `0x08` / `0x7F` | 上位机一般无需发送 |
| 不支持 | ANSI 转义、注释、引号包裹 | |

> **例外（字体容错）**：首字符若为 `1` / `i` / `I` 且余下恰好是 `k`，会被纠正为 `lk`（`main.c` 3825）。
> 即 `1k` / `ik` 等价 `lk`。单独输入 `i` 不受影响。

### 1.4 回包形态与解析（**上位机最容易出错的地方**）

固件返回 = **逐字符回显** + 命令输出 + 提示符：

```
<m>                    ← 你发的命令被逐字符回显
<命令执行输出...>       ← 各命令自己的格式
>_                     ← 提示符 "> "（每个非空命令行结束后打印）
```

**解析要求**：
1. **按行读**（以 `\r\n` 切分），**不要**用"读固定字节数"。
2. 丢弃：**回显行**（等于你刚发的内容）、**`> ` 提示符**、**`[RUN]` 开头的日志行**。
3. 用**关键词**判定结果（下表），并设整体超时。
4. 保留原始返回供排错显示（很多命令的输出是表格，用户需要看）。

| 判定 | 关键词 |
|---|---|
| 成功 | `OK`、`Saved`、`Stopped`、`complete`、`set to`、`saved`、`Done` |
| 用法错误 | `Usage:` |
| 执行失败 | `FAIL`、`FAILED`、`reject`、`NACK`、`unreachable`、`out of range`、`IK failed` |
| 安全拦截 | `path check fail`、`TCP z=`、`read FAILED`、`UNSTABLE`、`Another loop is active` |
| 急停 | `E-STOP` |
| 读失败 | `READ FAIL`、`no reply`、`read FAILED`、`offline` |

### 1.5 特殊模式下的限制

| 模式 | 限制 |
|---|---|
| 急停（`PE11` 低有效） | 轨迹立即停止；**只允许 `s` 和 `h`**，其余回 `E-STOP active!` |
| `teach` 录制中 | 白名单（`teach/rec/play/save/list/files/del/delete/compact/s/h/S/U/pv/pf/tm`）之外的命令会**自动先退出 teach** 再执行 |
| 示教回放中 | 除 `S`/`s`/`h` 外，命令会**先中止回放** |
| `W` 挥动 / `QL` / `QLC` / `B` / `BG` 循环中 | 期间禁用其它运动命令，需先 `S` |
| `c` 校准中 | **交互式阻塞**，需 `q` 退出 |

## 2. 文本命令全表（**已逐条核实**）

> 末尾均需 `\r\n`。`J` 的含义见 §2.1。

### 2.1 ⚠ 关节号的两种约定（**极易错**）

| 命令族 | J 取值 | 示例 |
|---|---|---|
| 单轴命令 `t` `a` `r` `p` `z` `w` `L` `M` `T` `O` `E` `U` | **0~5** = J1~J6 | `a 0 90` = J1 转到 90° |
| PID 命令 `K` `I` `D` `N` `Y` `A g` | **1~6** = J1~J6 | `K 1 16` = J1 的 P=16 |

### 2.2 ⚠ 角度的两套量纲（**极易错**）

| 量纲 | 范围 | 出现在 | 说明 |
|---|---|---|---|
| **舵机度** | 0~360° | **`a J deg`、`m`、`B`、`q`、`L` 的入参** | 舵机绝对角度（含零点偏移） |
| **关节角（rel-home）** | 可正可负（典型 −180~+180°） | 内部 IK、`g` 的 pitch、`f`/`p` 的 rel-home 输出、`ms`、`03` 协议 | 相对 Home 零点的角度 |

换算：`关节角 = JOINT_DIR[j] × (舵机度 − SERVO_OFFSET[j])`，`JOINT_DIR = [−1,+1,+1,+1,+1,+1]`。

> **⚠ 所有"输入 6 个数字"的运动命令（`a`/`m`/`B`/`q`/`L`）收的都是舵机度，不是关节角。**
> 唯一收关节角语义的是 `P 0~4`（预设位，内部由 `POSE_*_J` 关节角经
> `refresh_pose_servo()` 换成舵机度）与 `g`/`BG`/`qg` 的 `pitch` 参数。
> 把关节角填进 `m`/`q` 会得到一个"看起来执行成功、位置却完全不对"的结果 —— 这是最容易犯的错。

### 2.3 扫描与配置

| 命令 | 语法 | 说明 |
|---|---|---|
| `n` | `n` | 扫描 Bus A(1~3) 与 Bus B(4~6)，报 id/型号/版本 |
| `Z` | `Z` | 全 ID 扫描 1~253（诊断，慢） |
| `b` | `b` / `b 0\|1\|2` | 总线模式：0=正常(A:AABBB) 1=全 Bus A 2=全 Bus B；改后需 `n` 再 `i` |
| `i` | `i` / `i J`(J=0~5) | 初始化舵机：Torque OFF→RESET→舵机模式；**幂等但会重写 PID/限位/中位**，危险 |
| `s` | `s` | 6 轴状态：raw / 目标角度 / 负载 / 温度 / 硬件错误 |
| `c` | `c` | 进入**交互式校准**（Phase1 零点 / Phase2 限位）；`q` 退出，`s` 保存 |
| `M` | `M a` / `M 0\|1~5` | 一键置中（舵机 addr40 写 128 → 当前位置设为中位 2048）；`M a` = 全部 |
| `F` | `F` | 把 PID/修正/速度/参数/限位/零点写入 **Flash Sector 11**（掉电保留） |

|---|---|---|

| `a` | `a J deg` | 单轴运动到角度（**舵机度**；`clamp_angle()` 按 raw 限位钳制并回显 `J%d: x -> y deg`；**单轴直写、不走轨迹规划**） |

| `z` | `z J` / `z a` | 单轴 / 全部回 0 位（**用校准零点** `calib_zero_raw`；未校准时=2048）。**非阻塞**，到位查 `f` / `p J`；目标越出工作限位则**拒绝并打印**（不夹取、不半动）。⚠ 与 `P 0`（折叠收纳位）是**两个不同姿态** |

| `R` | `R 1` | **广播 reboot 两条总线上的所有舵机**（尝试恢复卡死/报错的舵机） |

### 2.5 协同运动

| 命令 | 语法 | 说明 |
|---|---|---|
| `m` | `m a1 a2 a3 a4 a5 a6 [v]` | 6 关节同时运动（**舵机度**，`v`=deg/s，**省略时用 `ARM_SC_DEF_VMAX`＝25**，不是帮助文本写的 30）。⚠ **数值先被硬钳到 `0~300`，超过 300 静默变 300**（`if (target[i] > 300) target[i] = 300;`）—— 这是与 `a`/`B`/`q` 唯一的差别 |
| `P` | `P 0\|1\|2\|3\|4` | 预设位姿：0=HOME 1=FOLD 2=READY 3=WAVE1 4=WAVE2 |
| `g` | `g x y z [pitch_deg]` | IK 笛卡尔运动（mm；pitch 缺省 0；限位/可达性/路径检查） |
| `f` | `f` | 显示末端位姿（FK：XYZ + 欧拉/pitch + raw） |
| `S` | `S` | **一键停止**：轨迹 / `QL` / `QLC` / `B` / `W` / `teach` 回放；通用 |
| `W` | `W n` | WAVE1↔WAVE2 来回 `n` 次（`n` 缺省 3；期间禁用其它命令，需 `S`） |
| `B` | `B a1..a6 b1..b6 rounds [v]` | 两姿态来回（**舵机度**，`clamp_angle` 按 raw 限位钳制；`rounds` 0=无限、>1000 钳到 1000；`v` 5~300） |
| `BG` | `BG x1 y1 z1 p1 x2 y2 z2 p2 rounds [v]` | 两姿态来回（XYZ，IK 求解；`rounds=0` 无限） |
| `q` | `q n j1..j6` | 存路点（`n`=1~8，**舵机度**，`clamp_angle` 按 raw 限位钳制；同时影响 `QL`/`QLC`） |
| `qg` | `qg n x y z [pitch]` | 存 XYZ 路点（内部解 IK 并校验，失败报 `IK failed`） |
| `qv`/`qV` | `qv n v` | 设第 `n` 段速度（deg/s，5~300） |
| `qd`/`qD` | `qd n ms` | 设第 `n` 点驻留（ms，0~60000） |
| `QL` | `QL n r [v]` | 多点循环 + **每点到点测量**（到点等 500ms 稳定→采样→驻留）；`r=0` 无限 |
| `QLC` | `QLC n r [v]` | 多点**连续**循环（段间不停顿/不测量/不驻留）；`r=0` 无限 |

> ⚠ **`QL` / `QLC` 必须大写 `Q`**（小写 `ql` 无效，会被当成路点存储命令报 Usage）。
> 而 `qv`/`qd`/`qg` 的**首字母大小写均可**（`q` 和 `Q` 都支持）。
> ⚠ 路点索引 **1~8**（`MULTI_POINT_MAX = 8`）；`QL`/`QLC` 的 `n` 必须 ≥2 且 ≤已存点数。
> ⚠ 有另一个循环在跑时会回 `Another loop is active. Use S first.`

### 2.7 监测与遥测

| 命令 | 语法 | 说明 |
|---|---|---|
| `tm` | `tm ms [字段]` / `tm 0` | 遥测：`p`=角度 `t`=温度 `i`/`c`=电流 `v`/`u`=电压 `s`=速度 `l`=负载 `a`/`*`=全部；`0`=停。**后台只读缓存，运动中建议 ≥100ms** |
| `G` | `G` / `G k` | 自适应修正 + PID 状态总览 / 设前馈 K（**占位，不参与运动算法**） |

> `tm` 是"边发边收"的分片采样：后台每 20ms 轮转 1 轴，打印只读缓存，**不占总线** ——
> 运动中也能持续回传。这是运动时**唯一推荐**的状态观测方式。

## 3. 二进制协议（同一串口）

### 3.1 帧格式

```
偏移   字段        说明
 0     0xAA        帧头1（文本命令首字符不可能是 0xAA，天然分流）
 1     0x55        帧头2
 2     SEQ         序号（响应回显，用于请求-应答配对）
 3     CMD         命令码
 4     LEN         负载长度 0~64
 5..    PAYLOAD     负载（小端定点编码）
 -2    CRC_LO      CRC16 低字节
 -1    CRC_HI      CRC16 高字节
```
- **总长 = 5 + LEN + 2**，最大 **71** 字节（`LEN ≤ 64`）。
- **CRC-16/CCITT-FALSE**：poly `0x1021`，init `0xFFFF`，**非反射**（MSB-first）。
- **CRC 计算范围 = SEQ, CMD, LEN, PAYLOAD**（即从偏移 2 开始，共 `3 + LEN` 字节）。
- **CRC 传输顺序：低字节在前**。
- 帧间字节超时 **200 ms** → 解析状态机复位（防半截帧卡死）。
- 收到 `0xAA` 后若下一个不是 `0x55`：丢弃该字节（保持等待 `0x55`）。

### 3.4 响应规则

- **数据查询类**：响应 CMD = 请求 CMD **| 0x80**（`0x01→0x81`、`0x02→0x82`、`0x21→0xA1`、`0x40→0xC0`、`0x42→0xC2`）。
- **控制类**：成功回 **ACK(0x7F)**，失败回 **NACK(0x7E) + 错误码**。
- **⚠ 请求-应答配对**：响应帧回显 **SEQ**，用 SEQ 匹配请求。
- **⚠ 与文本共用串口**：解析时必须先判 `0xAA 0x55`；否则会把二进制帧当文本行。

## 4. PID 调参（上位机"优化"能力的核心）

### 4.1 生效链（**UI 必须如实体现**）

| 动作 | 命令 | 生效范围 | 掉电保留 |
|---|---|---|---|
| 改缓存 | `K` / `I` / `D` / `N` | STM32 内存 | ❌ |
| 烧舵机 EEPROM | `Y J`（`Y 0`=全部） | 舵机自身 | ✅（⚠ 失力 ~0.6s） |
| 存 STM32 Flash | `F` | 固件开机自动下发 | ✅ |
| 恢复固件默认 | `X` | 只写 RAM | ❌ |
| **回读比对** | `N J` | 显示缓存值 vs 舵机 EEPROM 值 | — |

### 4.2 调参方向（内置提示）

| 增益 | 何时**增大** | 何时**减小** |
|---|---|---|
| **P**（位置刚度） | 到点偏软、负重下沉、稳态误差大 | 高频抖动、嗡鸣 |
| **I**（积分） | 到位后缓慢下沉、反复微调 | 低频来回晃、超调、积分饱和 |
| **D**（微分/阻尼） | 到点来回荡、过冲 | 高频剧烈抖动（**齿隙大的 J3 尤其敏感**） |

> 固件默认 PID（`main.c`）：`pid_p = {16, 32, 16, 16, 16, 16}`、`pid_i = {4,...}`、`pid_d = {12,...}`。
> 即 **P16（肩 J2 = 32）/ I4 / D12**。
> ⚠ **改 PID 前先记录基线**（`N 1`~`N 6`）。

### 4.3 建议的调参向导流程

```
1) N J                  记录基线（缓存 vs EEPROM 是否一致）
2) 单变量调整（一次只动一个关节、一个量）：
     到点下沉  -> K J <P+4~8>
     高频抖动  -> D J <D-4>        (J3 优先)
     缓慢下沉  -> I J <I+2>
3) 单关节验证：a J deg  /  m ...
4) 满意  -> Y J          （烧舵机 EEPROM；⚠ 弹窗提示托臂）
5) 全部满意 -> F         （存 STM32 Flash）
6) 变坏  -> X            （恢复默认，回基线重来）
```

### 4.4 硬性约束

1. **一次只改一个关节、一个量**，改完必须验证。
2. **`Y` 会让舵机关节失力约 0.6 s —— UI 必须弹窗要求用户托住机械臂。**
3. **`i` 会 Torque OFF → RESET**，危险操作，必须二次确认。
4. 改 PID 前必须记录基线（`N 1`~`N 6`）。
5. 别把"到点顿两下"当 PID 问题 —— 根因是尾段流式微步（参数 `#42 traj.approach_speed` / `#45 traj.handoff_deg`）。

### 6.1 会**静默改变你的输入**的钳制点（上位机务必自己先校验）

这些钳制**不报错、不回 `NACK`**，只是把值改掉后照常执行 —— 上位机如果只靠"有没有报错"
判断成功，就会得到"成功但位置不对"的幽灵 bug。

| 命令 | 静默钳制 | 源码位置 |
|---|---|---|
| `m` | 每轴 `0~300`（超 300 → 300）；`v` 钳到 `ARM_SC_V_MIN..V_MAX` = `5..300` | `case 'm'` |
| `a` / `B` / `q` | `deg_to_servo_raw` 把 `<0` 折成 `0`、`>360` 折成 `360`；再由 `clamp_angle` 钳到该轴 **raw 限位**（会打印 `J%d: x -> y deg`） | `cmdAngle` / `case 'B'` / `case 'q'` |
| `L J min max` | `min<0` → 0；`max>360` → 360；只有 `min>=max` 才报错 | `cmdLimits` |
| `B` / `BG` | `speed` 钳到 `5~300`；`rounds>1000` → 1000 | `case 'B'` |
| `BG` / `qg` / `g` | IK 结果越限时**不报错地退回**（J1 方位角被 `atan2` 收进 −180~180 后再由 raw 限位判定）→ 必须靠 FK 复核（≤5 mm）才发现 | `cmdSolveIKPoint` |
| `w`（sweep） | 不解析任何角度参数；直接在 **`JOINT_MIN_RAW`/`MAX_RAW`** 三点（min→mid→max→mid）各停 1.5 s，全程无路径检查 | `cmdSweep` |

**上位机应做的**：发送前用 SDK 的 `ik_checked()` / 本地限位表先校验，并在 UI 上把
"被钳制"和"被拒绝"用**不同颜色**显示（钳制 = 黄，拒绝 = 红）。

**钳制回显的确切格式**（固件原文，可用于精确解析）：

```text
  J3: 320 -> 300 deg (raw 4096 -> 4095 limit)      <- clamp_angle() 钳制某轴
  J1 limits set: 80 ~ 220 deg (raw 910 ~ 2503)     <- L J min max 设置成功回显
```

SDK 已提供解析（`resp.clamps()` / `parseClampLines()`），返回 0 基 `joint` 与
`joint_label`（如 `J3`）。**注意 `m` 的 0~300 钳制固件不打印**，只能靠 SDK 发送前拦。

**已知命令的失败串**（判定响应成功/失败必须认识这几个，否则会出现"假成功"）：

```text
  Unknown command 'x'. Type 'h' for help.          <- main.c:5719 未知命令
  Joint must be 0-5                                 <- 轴号越界
  Unknown pose 9. Available: 0=HOME ...             <- P 位号非法
  Segment index must be 1~8                         <- qv/qd 段号非法
  Cannot move. / Cannot enable torque.               <- 前置条件不满足
  Error: min must be < max (for wrap-around ...)     <- L 区间非法
```

> **以本文（`03_INTERFACE.md`）与固件 `h` 命令输出为准。**
