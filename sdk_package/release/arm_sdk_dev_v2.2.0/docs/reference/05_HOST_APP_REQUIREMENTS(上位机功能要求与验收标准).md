# 05_HOST_APP_REQUIREMENTS.md — 上位机功能要求与验收标准

> 这份文件**可以直接当需求书/验收清单**交给开发（人或 AI）。
> 每条需求都标了 **优先级**（P0 必须 / P1 应该 / P2 可选）和 **可测的验收方法**。
> 开发完成后，逐条对着"验收方法"过一遍即可。

---

## 0. 一句话需求

做一个**串口上位机**，通过 USB 转串口（USART6，115200 8N1）控制这台六轴机械臂：
能看到它现在在哪（数值 + 3D）、能让它动（关节 / 笛卡尔 / 预设位姿）、
能调它的 PID 和算法参数、能看它的运行状态与曲线，且**任何"没动 / 读不到 / 被拒绝"
都要在界面上说清楚原因**。

---

## 1. 范围

### 1.1 做

| 模块 | 说明 |
|---|---|
| 连接管理 | 串口枚举/打开/关闭、状态指示、断线重连提示 |
| 命令终端 | 全部文本命令可下发；自动 `\r\n`；另有"原始命令"透传框 |
| 收发日志 | 带时间戳的原始收发，可暂停/过滤/导出 |
| 状态面板 | 6 轴（舵机度 / raw / rel-home / 负载 / 温度 / 错误位）+ 末端位姿 |
| 3D 视图 | 用包内 URDF 或几何 JSON，实时显示姿态，**与固件 FK 数值一致** |
| 运动控制 | 关节运动、笛卡尔运动（IK）、预设位姿、单轴点动、停止/急停 |
| PID 调参 | 缓存/EEPROM 对比、改值、烧写、存盘、恢复默认、方向提示 |
| 参数表面板 | `LP` 解析成表格，`SP` 写回，标注"需 F 存盘" |
| 遥测曲线 | `tm` 数据实时成图（角度/电流/温度/负载） |
| 示教与路点 | `teach` 系列、`q`/`qg`/`qv`/`qd`、`QL`/`QLC` |
| 诊断页 | `n`/`Z`/`b`/`d`/`e`/`LL`/`U`/`R`/`T`/`O`/`E` |

### 1.2 **明确不做**（这一版）

| 不做 | 说明 |
|---|---|
| 主从臂（Leader/Follower） | `ms`/`ma`/`mf`/`sf`/`lk`、UART4 链路、`0x13` 流帧 —— **全部不实现**，界面上也不出现 |
| ROS / ROS2 接入 | 另一条技术路线 |
| 微秒级时间同步 | 串口特性不支持 |
| 云平台 / 远程控制 | 本版只做本地串口 |

> ⚠ 这一条要写进代码注释。开发过程中很容易"顺手"把 `03_INTERFACE.md` 里
> §2.11 提到的链路命令也做进去，那会让界面混乱且误导用户。

## 2. P0 需求（不做完不能用）

### P0-1 串口连接

| 项 | 要求 |
|---|---|
| 参数 | **115200 / 8 / None / 1 / 无流控**，硬编码，不提供 UI 修改（改了必然连不上） |
| 枚举 | 列出系统串口，显示设备名/描述（如 `COM11 - USB-SERIAL CH340`） |
| 打开后 | **清空收发缓冲**（否则会读到半截开机横幅） |
| 状态 | 界面明确显示 已连接/未连接/错误；发送失败要提示 |
| 关闭 | 释放端口；关闭前若在运动，提示先停止 |

**验收**：插上板子 → 枚举里出现该串口 → 打开 → 发 `h` 能收到帮助文本。

### P0-2 行尾（**最高优先级，最高频 bug 来源**）

**要求**
1. 所有命令**必须**以 `\r\n` 结尾。
2. 这个行为**封装在 SDK 的 `send_command()` 内部**，业务层**不可能**漏掉。
3. 提供"原始命令"输入框时，也在内部补 `\r\n`（除非用户显式勾选"不加行尾"）。
4. **禁止**业务代码自己拼命令行尾。

**验收**
- 发 `p 0`（不带行尾）→ 界面超时报错，**不是"无反应"**。
- 若你故意把行尾去掉，命令永不执行 ⇒ 说明这个封装确实是必需的。

### P0-3 响应分帧（按提示符）

**要求**：读到 `\r\n> ` 视为一条响应结束（固件每条命令后打印 `> `，不带换行）。
**不得**使用"读固定字节数"或"纯超时"策略。

**验收**：连续快速发 20 条 `p 0`，每条都能正确配对，不串行、不丢。

### P0-4 回包过滤与结果判定

**要求**
1. 丢弃：**回显行**、`> ` 提示符、`[RUN]` 日志行。
2. 用**关键词**判定（`03_INTERFACE.md` §1.4），**不要**用一个正则猜。
3. 判定顺序：急停 → 安全拦截 → 失败 → 用法错误 → 成功。
4. 保留原始文本供排错面板显示。

**验收**：见 §5 验收用例表。

### P0-5 异步行分流

**要求**：`TM `（遥测）、`  Feedback:` / `  Pose:`（`pv`/`pf` 周期输出）、`[RUN]`（日志）
**不得**进入命令响应解析，必须走独立回调。

**验收**：开 `tm 100`，然后连发 10 条 `p 0`；每条 `p 0` 的响应行数应为 1（不含 TM 行），
且曲线数据持续更新。

### P0-6 "读失败"如实上报（铁律）

**要求**

| 情况 | 必须显示 |
|---|---|
| `f` 无输出 | **"读取失败"** |
| `s` 某轴读失败（固件打 0.0） | 提示"该轴读数不可信，建议用单轴 `p J` 复核" |
| 二进制 `read_ok=0` 或关节 = `-32768` | **"读取失败"**，位姿 XYZ/pitch 置灰 |
| `pf` 某次无输出 | 曲线**断点**，不要插值连线 |

⚠ **严禁**用上一次的值或目标值填充。

**验收**：拔掉舵机总线 → 点"刷新状态" → 界面显示读取失败（**不是 (0,0,0)**）。

### P0-7 3D 视图与固件一致

**要求**
1. 几何**必须**来自 `model/arm_model.urdf` 或 `model/link_geometry.json`，
   **不要**用网上找的 SO-ARM100 官方 URDF 尺寸（差 ~5.6mm）。
2. 姿态用 **关节角（rel-home）** 驱动，不要用舵机度直接当关节角。
3. 读失败时 3D 视图必须**灰显/警示**，不能按旧值继续画。

**验收**（关键，务必做）
- 让机械臂停在一个姿态，固件敲 `f`，记录 `x/y/z/pitch`。
- 在 3D 视图里读取同一个姿态下的末端坐标（或 tooltip 显示）。
- **两者差值应 ≤ 1mm / ≤ 1°**（模型与固件是同一套公式，理论上是 0）。

### P0-8 运动控制与"被拒要说清"

**要求**
1. `m`（关节）、`g`（笛卡尔）、`P`（预设）三个入口。
2. **`S` 停止**按钮在任何状态下都可点，且立即生效。
3. **急停状态**（`E-STOP`）时：全屏红条 + **禁用所有运动按钮**，只留 `s`/`h`。
4. 运动被拒时，把固件回显的**原因**显示出来（"路径不安全" / "超出限位" / "不可达" / "俯仰未达成"）。
   **禁止静默失败。**

**验收**
- 发 `g 900 0 200 90`（超臂展）→ 界面显示"不可达/超限位"，**不能**什么都不显示。
- 长距离运动中途点 `S` → 立即停下来，界面显示"已停止"。

### P0-9 危险操作二次确认

| 命令 | 确认文案要点 |
|---|---|
| `i` / `i J`（初始化舵机） | "会重写 PID / 限位 / 中位，确定继续？" |
| `M a`（全部置中） | "会把当前位置当作中位（raw 2048），确定？" |
| `Y J` / `Y 0`（烧 EEPROM） | **"Jx 将失力约 0.6 秒，请先托住机械臂！"** —— 必须显式确认 |
| `R 1`（广播重启） | "两条总线所有舵机会重启，确定？" |
| `B` / `W` / `QL` / `QLC`（循环） | "机械臂会持续循环运动，确认周围安全" |
| `c`（校准） | "交互式校准会阻塞，期间无法下发其它命令" |

**验收**：点 `Y 3` → 弹窗要求确认且文案含"托住"字样。

### P0-10 命令串行化

**要求**：SDK 内部保证"同一时刻只有一条命令在途"（文本命令回包无请求 ID，并发必乱）。
UI 上同时只能有一个"进行中"操作。

**验收**：快速连点 10 次"刷新状态"，日志里不出现串行错乱（每条请求后面紧跟自己的响应）。

## 3. P1 需求（应该做）

### P1-1 状态面板

| 显示 | 来源 | 说明 |
|---|---|---|
| 6 轴舵机度 | `s` / 二进制 GET_STATUS | 单位 °，1 位小数 |
| 6 轴 raw | `p J` | 0~4095 |
| 6 轴 rel-home | `p J` / `f` 的 relhome 行 | 带正负号 |
| 负载 | `O` 或 `tm l` | 有符号 |
| 温度 | `T` 或 `tm t` | °C，> 60 标黄，> 70 标红 |
| 错误位 | `E` | 非 0 要显著提示 |
| 末端位姿 | `f` / GET_STATUS | X/Y/Z (mm) + pitch (°) |
| 急停状态 | GET_STATUS bit0 | 红条 |
| 轨迹执行中 | GET_STATUS bit1 | "运动中"指示 |
| 修正进行中 | GET_STATUS bit2 | 状态文字 |

**状态刷新策略（重要）**
- **空闲时**：`s` 或 GET_STATUS 每 **200~500 ms** 一次即可。
- **运动中**：用 **`tm`（遥测缓存）**，建议 **≥100 ms**。
  ⚠ **不要**在运动中高频轮询 `s`/`p` —— 那些命令会**占用总线**，会打断 6 轴同步写、
  导致机械抖动。`tm` 是"边发边收"的分片采样（后台每 20ms 轮转 1 轴，约 120ms 刷完 6 轴），
  不占总线，是运动时**唯一推荐**的观测方式。

**验收**：运动中把刷新率拉到 100Hz 用 `s`，观察机械臂抖动；换 `tm` 后抖动消失。

### P1-2 PID 调参面板

**要求**
1. 6 轴 × (P, I, D) 表格；每格显示 **缓存值**。
2. 每轴显示 **EEPROM 值** 与 **是否一致**（`N J`；注意固件 EEPROM 行的字段顺序是 **P D I**）。
3. 不一致的轴**高亮**并提示"需 Y 烧写"。
4. 提供按钮：`K/I/D` 改值、`Y J` 烧写、`F` 存盘、`X` 恢复默认。
5. **内置调参方向提示**：
   - P ↑：到点偏软 / 负重下沉；P ↓：高频抖动、嗡鸣
   - I ↑：到位后缓慢下沉；I ↓：低频晃动、超调
   - D ↑：到点来回荡、过冲；D ↓：高频抖动（**齿隙大的 J3 最敏感**）
6. 默认值提示：`P=[16,32,16,16,16,16]`（肩 J2=32）、`I=[4]×6`、`D=[12]×6`。
7. 提示"**到点顿两下不是 PID 问题**，去看参数 `#42 traj.approach_speed` / `#45 traj.handoff_deg`"。

**验收**：`N 3` 读值 → `N 3 16 4 12` 改 → 表格变黄 → `Y 3`（弹窗确认）→ `N 3` 显示"一致"
→ `F` → **断电重启** → `N 3` 读数与改后一致。

### P1-3 参数表面板

**要求**
1. `LP` 解析成表格：`id / 名称 / 当前值 / 范围 / 单位`。
2. 可编辑，用 `SP id value` 写回（自动范围钳制）。
3. 写了之后显示"**仅改 RAM，需 F 存盘**"提示与按钮。
4. ⚠ **不要硬编码 id 集合** —— 以 `LP` 实际输出为准（固件刻意保持表长稳定，
   但注释里写明"表项数变化会作废 Flash 记录"）。

**验收**：改一个参数 → 提示未存盘 → `F` → 重启 → 值保持。

### P1-4 遥测曲线

**要求**
1. `tm <ms> [fields]`，字段可多选（`p` 角度 / `t` 温度 / `i` 电流 / `v` 电压 / `s` 速度 / `l` 负载）。
2. 6 轴分色，可隐藏单轴。
3. **缺值（`--`）要断开曲线**，不能画成 0。
4. 可暂停/清除/导出 CSV。
5. 默认 `pti`（角度/温度/电流），间隔 100~200ms。

**验收**：拔一根舵机线 → 该轴曲线出现断点，其它轴不受影响。

### P1-5 命令终端与日志

**要求**
1. 命令分组下拉（扫描配置 / 单轴控制 / 协同运动 / 示教 / 监测 / 运动学 / PID / 参数 / 诊断）。
2. 每个命令带**参数提示**与**示例**，参数用表单而不是让用户背语法。
3. 原始命令透传框（给高级用户）。
4. 日志：时间戳 + 方向（TX/RX）+ 原文；可暂停、可按关键字过滤、可导出 `.txt`。
5. 命令历史（上下键 / 列表）。

**验收**：不用查文档，仅凭界面就能发出 `m`、`g`、`N J P I D`、`SP id v`。

### P1-6 示教与路点

**要求**
1. `teach` / `teach free` / `teach pwm` / `teach exit` / `teach lock` 按钮。
2. **进入示教前必须提示**：`teach` 的混合模式只让 J2/J3/J4 有力控辅助，
   J1/J5/J6 是真 free（会因重力下落）—— 提醒用户扶住。
3. 示教中显示"示教中（50Hz 采样）"状态；退出时提示已录多少点。
4. `save <name>` / `list` / `play [#|name] [loop]` / `del` / `compact` 做成列表+按钮。
5. 路点：`q n j1..j6`（**舵机度**，不是关节角！）、`qg n x y z [pitch]`、`qv n v`、`qd n ms`，
   然后是 `QL n r [v]`（到点测量）与 `QLC n r [v]`（连续）。
6. ⚠ **`QL`/`QLC` 必须大写 `Q`**（小写会被当成路点存储报 Usage）。
7. ⚠ 有循环在跑时其它运动命令会回 `Another loop is active. Use S first.` —— 要显式提示。

**验收**：录一段示教 → 存 `demo1` → 断电重启 → `list` 里还有 → `play demo1` 能回放。

### P1-7 诊断页

| 命令 | 用途 |
|---|---|
| `n` | 扫描 Bus A/B，显示 6 颗舵机 id/型号/版本，缺哪个标红 |
| `Z` | 全 ID 扫描 1~253（慢，给个进度提示） |
| `b 0/1/2` | 总线模式切换（0=正常 A:AABBB，1=全 Bus A，2=全 Bus B）；提示改后要 `n` 再 `i` |
| `T` / `O` / `E` | 温度 / 负载 / 硬件错误位 |
| `U J A [val]` | 舵机寄存器直接读写（高级调试） |
| `R 1` / `R` | 广播 reboot / 重置自适应修正 |
| `LL 0~4` | 运行日志级别 |
| `d` / `e` | CAN 自检（本版可能用不到，留着） |
| `A` | 自适应修正配置（开关/阈值/轮数/各轴增益） |
| `G` | 自适应修正 + PID 总览（⚠ 前馈 K 是**占位**，不参与运动算法） |
| `C` / `C dx dy dz` | 世界坐标系标定偏移（mm） |
| `V` | 舵机内部速度限值（⚠ 这**不是**轨迹速度，是舵机自身的） |

⚠ 特别提醒 UI：`G k` 设置的**前馈 K 是占位，不参与运动算法**。
不要把它做成"关键调参项"误导用户。

### P1-8 校准向导（`c` 交互式）

**要求**
1. `c` 进入后固件**阻塞在读字符状态**，**没有提示符**。
   ⇒ SDK 的 `send_command` 会超时，必须切到"逐字节透传模式"（`write_raw`）。
2. 界面提供一个"校准终端"：显示固件引导文字，用户按键直接发送（单字符，无需 `\r\n`）。
3. 明确显示流程：Phase1（摆官方 Home → `0` 记录零点）→ Phase2（逐轴推挡块 → 记录限位）
   → `s` 保存 → `q` 退出。
4. 退出后必须**重新读取限位**（`L`）并刷新本地 IK 限位。

**验收**：进入 `c` → 能按 `0` 记录 → `s` 保存 → `q` 退出 → `L` 显示新限位。

## 5. 验收用例表（可直接当测试用例）

| # | 操作 | 期望结果 | 对应需求 |
|---|---|---|---|
| 1 | 打开不存在的串口 | 明确报错，不崩溃 | P0-1 |
| 2 | 发 `h` | 显示帮助文本，回显被过滤掉 | P0-3/P0-4 |
| 3 | 发 `p 0` | 解析出 raw / 舵机度 / rel-home | P0-4 |
| 4 | 连发 20 条 `p 0` | 全部正确配对，无串扰 | P0-3/P0-10 |
| 5 | 发 `xxxx`（不存在的命令） | 显示 "Unknown command" **且必须是"失败"红色态**（`ok=false`）—— 不能显示成功 | P0-4 |
| 6 | `K 9 10`（J 越界） | 显示 `Usage:` 属于"参数错误" | P0-4 |
| 7 | 开 `tm 100` + 连发 `p 0` | 响应行数正常，曲线在动 | P0-5 |
| 8 | 拔一根舵机线 → `s` | 该轴显示"读取失败/不可信"，**不是 0** | P0-6 |

## 6. 反模式清单（看到自己在这么做，立刻停）

| ❌ 反模式 | ✅ 正确做法 |
|---|---|
| 用"读固定字节数"接收回包 | 按 `\r\n> ` 提示符分帧 + 整体超时 |
| 用一个正则猜结果 | 关键词集合 + 判定顺序（`03_INTERFACE.md` §1.4） |
| 把 `\n` 和 `\r\n` 混着发 | 统一 `\r\n`，且由 SDK 强制 |
| 让业务代码拼命令字符串 | 用 SDK 的高层方法 |
| 把 6 个舵机度直接当"关节角"作图/驱动 3D | 用 rel-home 关节角，或直接 XYZ |
| 把"读失败"显示成 0 / 上一次值 | 显示错误 + 灰显 |
| `i` / `M a` / `Y` 一键无确认执行 | 二次确认 + `Y` 必须提示托臂 |
| 自己发明命令（`MOVE`/`SETPID`/`HOME`） | 只用 `03_INTERFACE.md` 里核实过的命令 |
| 在运动中高频轮询 `s`/`p` | 用 `tm` |
| 用 `s` 表判断"读成功" | `s` 读失败会打 `0.0`，无法区分；用 `p J` 或 GET_STATUS |
| 硬编码参数表 id 集合 | 以 `LP` 输出为准 |
| 硬编码限位/位姿（舵机度） | 一律关节角/XYZ；限位用 `L` 读回 |
| 把 `G k` 的前馈当关键调参 | 它是**占位**，不参与运动算法 |
| 把"到点顿两下"当 PID 问题 | 看 `#42/#45` 参数 |
| 只看 `resp.ok` 判断成功 | 固件有**假成功**（`Unknown command` 曾落进兜底）和**静默改值**（钳制），要同时看 `kind` 与 `clamps()` |
| 手拼 `"m " + 角度` | 走 `move_joints()`；`m` 的 0~300 钳制固件**不打印**，只能发送前拦 |
| 把 `m`/`B`/`q` 当"关节角"输入 | 它们是**舵机度**；关节角只出现在 `g`/`BG`/`qg` 的 pitch 与 `P 0~4` 内部 |

## 6.1 必须写进 UI 的"黄/红"两态

| 颜色 | 触发 | 文案示例 |
|---|---|---|
| 🔴 红 = **被拒绝** | `kind ∈ {fail, safety, estop}` 或 IK/路径检查失败 | "被拒：超出关节限位（J4），未执行" |
| 🟡 黄 = **被钳制** | `resp.clamps()` 非空 | "J3 被限位钳制：320° → 300°，已按 300° 执行" |
| ⚪ 灰 = **读失败** | `kind == 'empty'`（`f`/`pf` 静默）或哨兵 `-32768`/`servo<0` | "读取失败（不显示旧值）" |

> 这三种**绝不能**都显示成"成功"。`03_INTERFACE.md` §6.1 有完整的静默钳制清单。
