# 网口下发操作手册（UDP / armctl）— 2026-09-30

> **适用**：Ubuntu 22.04 上位机（cjky-Q570）↔ ArmControl_HAL 固件 `ARM-NET-0924AV`。
> **工具**：`arm_sdk-2.2.0`（装好才有 `armctl`）。
> 本文档只讲**网口下发**；串口操作见《串口下发操作手册》。协议字节层疑问 →《网口指令大全》。

---

## 1. 操作步骤（按顺序走，每步都标了"算通过"）

### 步骤 0：安全底线（动臂之前必读）

- 固件**没有看门狗**；运动命令会让臂真动，第一次动手边留好断电/急停手段。
- **绝不用 `M a` / `center`**（=标定，松力矩整臂塌）；老固件别敲 `cx`。
- 任何 PC 运动命令都会**解除 RC 手柄武装**（之后要重新双击 START 或 `rc go on`）。

### 步骤 1：配置变量（每开一个终端做一次）

```bash
export ARM="net://192.168.7.XXX:5000"   # ← 换成臂的真实 IP
```

- 这只是设置 shell 变量（省字用），**不是**建立连接；真正的连接发生在带 `--uri $ARM` 的命令执行时。
- 臂的真实 IP 从哪来：串口敲 `h`，首行 `udp=192.168.7.XXX:5000` 就是（见串口手册 §4.1）。
- 新终端要重新 export；想一劳永逸：`echo 'export ARM="net://…"' >> ~/.bashrc`。

### 步骤 2：探活（三条全绿才继续）

```bash
armctl --uri $ARM ping          # 算通过：✓ PING proto_ver=1 run_id=NN
armctl --uri $ARM preflight     # 算通过：fw-tag 是 0924AV、无红字
armctl --uri $ARM status        # 算通过：六个数字，没有 None
```

ping 不通排查：IP 对不对 → 网线 → `sudo ufw status` 放行 → 臂是否在网口模式（串口 `link net` → `link save` → 按 RESET，**别断电**）。

### 步骤 3：只读观测（随便敲，无副作用）

```bash
armctl --uri $ARM detail        # 六轴遥测：角度/速度/负载/电压/温度
armctl --uri $ARM fk            # 末端位姿 X/Y/Z/pitch
armctl --uri $ARM flags         # 状态位图（estop=True 时动不了，先排查）
```

### 步骤 4：第一次运动（回中位，低速）

```bash
armctl --uri $ARM home --wait   # 全轴回中位 180°，速度默认 10 deg/s
# 算通过：到位检查行六个角度都是 180 左右，无黄色钳制提示
```

### 步骤 5：小步点动（单轴 ±5° 试手感）

```bash
armctl --uri $ARM jog 0 5 --v 10    # J1 +5°，其余五轴保持
armctl --uri $ARM jog 0 -5 --v 10   # 走回去
# 出任何意外：armctl --uri $ARM stop   （平滑停，不松力矩）
```

### 步骤 6：收工

```bash
armctl --uri $ARM fold --wait       # 回折叠收纳位（= P 0，RC 手柄 CIR 键同款）
# 或松力矩（⚠ 臂会当场垂下，先扶/垫）：armctl --uri $ARM torque --off
```

## 2. 命令参考（v2.2.0 全量，逐条注释）

> `⚠` = 必须加 `--yes` 才执行，不加只打印后果。

### 2.1 观测（只读，随便敲）

| 命令 | 作用与注释 |
|---|---|
| `armctl --uri $ARM ping` | 链路探活；`--repeat 200` 兼测延迟 |
| `armctl --uri $ARM preflight` | 前置体检：fw-tag/零点/限位/丢读率 |
| `armctl --uri $ARM status` | 六轴当前角（舵机度）+ flags；某轴 None=该拍读失败，重试 |
| `armctl --uri $ARM detail` | 六轴遥测表：角度/速度/负载/电压/温度（默认 5 拍中位数抗丢读；`--avg N` 改拍数） |
| `armctl --uri $ARM fk` | 正解：末端 X/Y/Z(mm)/pitch(°)；原点=J1 轴心，X 前 Y 左 Z 上 |
| `armctl --uri $ARM ik <x> <y> <z> [pitch]` | **只解算不运动**：给 XYZ 看六关节解 + 限位/FK 校验是否通过 |
| `armctl --uri $ARM flags` | 状态位图：estop/traj/corr…（不碰舵机总线，可 10~50Hz 轮询做 UI） |
| `armctl --uri $ARM limits` | Flash 校准限位 + Home 零点；**报错误码 7 = 没标定过，不是线缆问题** |
| `armctl --uri $ARM pid <0~5>` | 单轴 PID（舵机 EEPROM 权威值；from_eeprom=False=读失败，值不可信） |
| `armctl --uri $ARM gravity` / `gravity 0.05` | 重力前馈 K(deg/mm) 读 / 设 |
| `armctl --uri $ARM corr get` / `on` / `off` | 自适应修正（`--thr` 阈值 `--rounds` 轮数） |
| `armctl --uri $ARM log <0~4>` | 固件 RunLog 级别：0=关 1=err 2=warn 3=info 4=debug |
| `armctl --uri $ARM info` / `selftest` | SDK 能力摘要 / 228 项离线自检（不碰硬件） |

### 2.2 运动（真会动）

| 命令 | 作用与注释 |
|---|---|
| `home --wait` | 全轴回中位（= move 六个 180）；**第一条运动命令先敲它**，给所有轴留双向行程 |
| `fold --wait` | ★ 一键回**折叠收纳位**（底层 = `P 0`，RC 手柄 CIR 键同款） |
| `pose <0~4>` | 预定义位姿：**0=HOME(真折叠)** 1=FOLD(备用收拢) 2=READY 3/4=WAVE 演示 |
| `jog <0~5> <deg>` | 单轴点动，**其余五轴保持**；默认相对当前角，`--abs` 绝对舵机度；`--v` 速度 |
| `move "<六元组>" --v N` | 六轴联动，**舵机度**域（180=中位，0~300 硬钳制） |
| `move --delta "<六元组>" --v N` | 六轴**增量**点动（★点动必须 --delta，不加就是绝对角全轴都走） |
| `cart <x> <y> <z> --v N` | 笛卡尔直线(mm)；⚠ 会把 J5/J6 归零（爪尖姿态被重置） |
| `stream --sec 2 --hz 50` | 50Hz 流式（逻辑角域，验证链路用） |
| `stop` | 平滑停止当前轨迹，**不松力矩**；出事先敲这条 |
| `torque --off` / `torque on` | 松/上力矩；松力矩=臂当场垂下，先扶/垫；`--joint N` 只操作单轴 |

⚠ **两套角度域不可混用**（历史头号坑）：`move`/`jog`/`pose` 用**舵机度**（180=中位）；`stream --pose` 用**逻辑角**（0=Home 位）。

### 2.3 参数 / 示教文件

| 命令 | 作用与注释 |
|---|---|
| `params list` / `get <id>` / `set <id> <val>` | 运行时参数表；⚠ 超范围**静默钳制**（err=0 不代表写成功） |
| `params save` | 参数落盘 Flash（= 文本 `F`，重启保持） |
| `teach total` / `list` / `show <n>` / `del <n>` / `compact` | 板载示教文件：总览/列举/看样本/删除/回收空间 |

### 2.4 系统 / 校准（⚠⚠ 一律 `--yes`）

| 命令 | 作用与注释 |
|---|---|
| `zero reset [--save] --yes` | Home 零点复位回出厂中位（= `zr`）；量纲基准改变；`--save` 写 Flash 固化 |
| `init [0~5] --yes` | 舵机初始化：重写 PID/限位/中位并 RESET（= `i`）；**Torque ON 臂会绷紧** |
| `busmode <0/1/2> --yes` | 总线模式：0=正常 A:AABBB / 1=全A / 2=全B（纯调试） |
| `reboot --yes` | 整板软复位：先回 ACK、150ms 后真复位；**力矩全掉臂下沉**，链路按 Flash 偏好重建 |
| `center --yes` | ⚠⚠ 六轴推 raw 2048 居中（= `M a`），**改变量纲基准、不可逆**，仅标定流程用 |

> 固件设计上**网口不可用**的校准向导（文本 `c`，交互式）刻意没封装——从网口进会卡死主循环（无看门狗）。

### 2.5 透传（`text --cmd`：控制台命令全部可从网口发）

```
UDP :5000
 ├─ 38 条二进制命令（move/status/fk/params/teach…）→ 上面 2.1~2.4 的专属子命令，回传结构化
 └─ TEXT_EXEC (0x0B) 透传                          → 固件控制台 ~124 条命令全部可达，回显纯文本
```

```bash
armctl --uri $ARM text --cmd "rc diag"   # PS2 手柄接线诊断
armctl --uri $ARM text --cmd "nx"        # 网口体检（长回显，SDK 已自动翻页）
armctl --uri $ARM text --cmd "zf 5"      # 设桌面下限：爪尖最低离桌 5mm
armctl --uri $ARM text --cmd "link"      # 查链路
armctl --uri $ARM text --cmd s --cmd L --cmd zi   # --cmd 可重复，按顺序执行
```

⚠ 透传=真的在敲控制台：`m` 会动臂、`t J 0` 会松力矩、`zr` 动基准。副作用清单见《串口下发操作手册》§2。

## 3. 高频坑速查

| 现象 | 原因 → 解法 |
|---|---|
| ping 不通 | IP 不对（串口 `h` 看 `udp=`）→ 网线 → 防火墙 → 臂不在网口模式（`link net` 三连+RESET） |
| `move` 走错角度 | 域混了：move=舵机度（180=中位），stream=逻辑角（0=Home） |
| err=0 但没到位 | 超限被**静默钳制**；必须回读看角度，不能只看 err |
| `cart` 爪尖转正 | cart 归零 J5/J6，正常行为；要保姿态用 move/jog |
| 承重轴读数抖 | 单拍丢读（~25% 是总线现状），重试；轮询别快于 100ms |
| 手柄突然没反应 | PC 运动解除了 RC → `rc go on` 或双击 START |
| 长回显只看到一截 | `nx`/`h` 超一页；armctl `text` 已自动翻页，手搓客户端必须按字节拼页 |

## 4. 回传样例（真实输出逐字段注解）

> 来源：armctl 输出由 SDK 模拟器实跑抓取（格式化代码与真机同源）；不是手编。

### 4.1 `ping`

```
✓ PING proto_ver=1 run_id=90  3.3ms
│           │          │         └─ 往返延迟（真机 UDP 实测 p50 ~1.6ms）
│           │          └─ 固件每次复位随机生成的会话 ID（变了=臂重启过）
│           └─ 协议版本号（当前 1）
└─ ✓ = 收到合法 ACK（0x81）
```

### 4.2 `status`

```
[180.0, 180.0, 180.0, 180.0, 180.0, 180.0]  X=361.9 Y=0.0 Z=244.3 pitch=87.8  3.1ms
│                                            │                                └─ 往返延迟
│                                            └─ FK 换算的末端位姿（mm / deg）
└─ 六轴当前角，**舵机度**。任一轴 None ⇒ 该拍读失败，重试，别当 0 用
```

### 4.3 `detail`

```
  轴        角度deg     速度     负载     电压    温度C
  J1       180.0        0        0    12.00       42
  ...
  （5 拍取中位数抗瞬时丢读；— = 该字段全拍丢失，不是 0 值）
```

### 4.4 `move "180,..." --v 10 --wait`

```
  当前舵机度 [180.0, ...]  flags(estop=False traj=False corr=False read_ok=True)
  │                        │      │      │      │        └─ 本拍是否全轴读到
  │                        │      │      │      └─ 自适应修正进行中
  │                        │      │      └─ 轨迹执行中
  │                        │      └─ 急停标志（True=被急停，先排查再动）
  绝对模式：目标 [...]（⚠ 超限会静默钳制，err=0 不代表到位）
  ✓ MOVE_JOINTS (2.2ms)
  到位检查（err=0 不代表动了，必须看角度）：[180.0, ...]
```

`--delta` 时第二行变为：`增量模式：当前 [...] → 目标 [...]`。

### 4.5 `fold --wait` / `pose 0`

```
  当前舵机度 [...]  flags(...)
  位姿 0 = HOME=折叠收纳位(推荐)
  Pose 0 (HOME): 213 143 232 139 180 180      ← 固件 cmdPose 回显：目标六轴舵机度
  Move started.
  当前角度（err=0 不代表动了，必须看角度）：[...]
```

被拒时的样子（保护性动作）：`折叠位: E-STOP 激活, 拒绝` / `折叠位: 有运动/回放进行中, 拒绝`。

### 4.6 回显四态判读

| 状态 | 样子 | 处置 |
|---|---|---|
| 🟢 成功 | ✓ ACK、无钳制提示 | 继续 |
| 🟡 被钳制 | "requested vs applied" 两行数值 / `J3: 320 -> 300 deg` | **正常防护**：撞限位被软拦，改小目标 |
| 🔴 拒绝 | 错误码 / ERR / NACK | 先 `stop`，按错误码查表；状态类报 7=舵机总线读失败，`limits`/`pid` 报 7=Flash 没写过 |
| ⚪ 读失败 | 某轴 `None` / `read_ok=0` | 丢弃该拍重试，**别拿 0 兜底** |
