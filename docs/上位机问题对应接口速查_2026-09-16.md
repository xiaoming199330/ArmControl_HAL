# 《软件优化方案》问题 → 固件接口速查

> 日期：2026-09-16　来源：`04-文档-标签模板/软件优化方案.docx`
> 说明：逐条给出**固件侧已有的**接口（命令 / 函数），软件照此改即可，绝大多数不需要等固件出新版本。
> 所有接口同时存在于 **文本控制台**（ASCII 命令）与 **二进制帧**（`0xAA 0x55 …`，CRC16-CCITT）两套通道，二选一。

---

## 1. 按轨迹执行时"一抖一抖的缓慢往下坠"

| 项 | 接口 |
|---|---|
| 轨迹执行（推荐） | `m a1 a2 a3 a4 a5 a6 [v]` — 六轴关节空间 S 曲线一次走完；`v` = deg/s（默认 30，范围 5~300）。二进制 `0x10 MOVE_JOINTS`：6×i16 角度×10 + u16 v×10 + u16 a×10 |
| 多点循环 | `QL <n 2~8> <r 0=∞> [v]` 逐段停稳（带到位误差统计）／`QLC <n> <r> [v]` 段间不停顿的流水线循环 |
| 停止 | `S`（文本）／ `0x11 STOP`（二进制） |
| ⚠ 不要拿 `g` 当"轨迹播放" | `g x y z [pitch]` 走的是**安全路点序列**：`cmdGotoSafePlan()`（main.c:2848）会把目标拆成"抬肩 → 展肘 → 翻腕"多段逐段 FK 校验后再走。逐点发 `g` 做轨迹执行，外观正是"一段一段抖 + 往下坠"。逐点执行请改用 `m` 或 `QL` |
| ⚠ 轨迹期间不要同时开位置流 | `sp` / `sf` / `#P` / `0x13` 的流目标与插补目标会互抢总线；`cmdMove()` 每次进入都先执行 `cmdStreamExit("trajectory move")`，两者不能并存 |
| ⚠ 关掉控制台回显 | `ec 0`（或 `LL 0`）。`m` 每次都会打印 PRE-CHAMP/POST-CLAMP 与 From/To 两组长行，而 `cprint` 是**阻塞**写串口的；高频发 `m` 会被打印拖慢节拍，这本身就会抖 |
| 相关函数 | `cmdMove()` main.c:1431 · `ArmApi_MoveJoints()` Core/Src/arm_control_api.c · `Trajectory_Plan()` Core/Src/trajectory.c |

## 2. 窗口一直有角度/温度/电流输出，但表格与曲线是空的

固件**已经在持续输出**，缺的是软件侧解析入库：

| 输出源 | 格式（可直接按空格 split） |
|---|---|
| `tm <ms> [ptivsl]` | 每字段**单独一行**、6 个值空格分隔、无效位为 `--`：<br>`TM p:` 角度(°) · `TM t:` 温度(℃) · `TM i:` 电流(mA) · `TM v:` 电压(V) · `TM s:` 速度 · `TM l:` 负载<br>采样按 20ms 轮转（每拍 1 轴），打印周期可调；`tm 0` 停止 |
| `pv <ms>` / `pf <ms>` | `Feedback: J1=.. J2=.. … J6=..` ／ `Pose: X=.. Y=.. Z=.. mm  Pitch=.. deg`（只读缓存，不占总线） |
| 二进制 `0x02` → `0x82` | 固定 21 字节：`6×i16 舵机度×10` → `i16 x,y,z (0.1mm)` → `i16 pitch (0.1°)` → `1B 标志位`（bit0 E-Stop / bit1 traj_active / bit2 corr_active / **bit3 read_ok**）<br>**建议 20~50Hz 轮询，直接填表 + 画曲线**（每次会读六轴总线，不要超过 50Hz） |
| 相关函数 | `TelemetryPrintService()` main.c:431 · `cmdRealtimeFeedback()`:3582 · `cmdRealtimePoseFeedback()`:3597 · `ArmApi_GetStatus()` |

## 3. `P 0` 折叠位：实物到位、模型不动 ＋ 单关节拖动

| 需求 | 接口 |
|---|---|
| 复位 = 折叠位 | `P 0`（HOME）。实测舵机度 ≈ `178.8 76.2 270.3 250.6 182.7 140.4`，与文档"编号1"一致。可用姿态：`0=HOME 1=FOLD 2=READY 3=WAVE1 4=WAVE2` |
| 模型要跟实物同步 | 发完 `P n` 后**轮询** `f`（或 `0x21 FK_QUERY → 0xA1`）取**实到**位姿刷模型；也可常开 `pf 200` 让固件自己吐位姿 |
| 新增"置0位"按钮 | `z a`（六轴回 0 位）/ `z J`（单轴）。**目标 = 校准零点 `calib_zero_raw`**（未校准时回落 2048），由 `SERVO_OFFSET[]` 决定；非阻塞，发完轮询 `f` / `0xA1` 确认到位 |
| ⚠ "置0位" ≠ "复位" | `z` 去的是**各关节 rel-home 角为 0 的 L 形中位**；`P 0` 去的是**折叠收纳位**（实测舵机度 `178.8 76.2 270.3 250.6 182.7 140.4`，J2 关节角 −103.65°）。这是**两个不同姿态**，GUI 上两个按钮的文案要写清，别都叫"复位" |
| ⚠ 改版说明（2026-09-17 固件） | 旧版（≤09-16）的 `z` 把目标**写死 raw 2048**、不查限位/E-STOP、卡住还会阻塞等待（六轴最坏 90 s）、结束时把六轴力矩全关。新版：目标跟随校准零点、越出工作限位**拒绝并打印**（不夹取、不半动）、非阻塞、不再关力矩。如果手上固件是旧的，行为按旧的接 |
| 单关节拖动下发 | **用 `a J deg`**（`a <0~5> <0~300>`，`cmdAngle()` main.c:3634）：只写这一路目标、不读起点、不做轨迹规划，其余轴保持不动（舵机保持上次目标）。**不要用 `m`** —— `m` 是六轴一次规划，会把没被拖动的轴也一起下发目标 |
| 相关函数 | `cmdPose()`:3327 · `cmdGoHome()/cmdGoHomeAll()`:3672/3696（`SERVO_SetGoalRaw()` servo_driver.c:761 · `SERVO_SetPositionsRawSync()`） · `cmdAngle()`:3634 |

## 4. 路点读取当前角度（J1/J3/J4/J5 对，J2/J6 错）

> 根因：软件取值取错了行。固件**原生同时给两种量纲**，路点表要取 `servo`（舵机度）。

`f` 一条命令打印三行（`cmdFK()` main.c:3372）：

```
FK: x=130 y=-20 z=210 mm  pitch=44 deg      ← 位姿（"新增读取当前坐标位 x y z [pitch]"就用这行）
servo  : J1=.. J2=.. J3=.. J4=.. J5=.. J6=.. deg   ← ✅ 路点表取这行（舵机度 0~360）
relhome: J1=+.. J2=+.. J3=+.. J4=+.. J5=+.. J6=+.. deg  ← ❌ 别取这行（关节角 rel-home，可正可负）
```

二进制 `0x21` → `0xA1`（同样 21B）：`x,y,z i16 (0.1mm)` + `pitch i16 (0.1°)` + `6×i16 舵机度×10` + `1B read_ok`。
**这条帧里只有舵机度、没有 rel-home** —— 用二进制通道就不会再混量纲。

相关函数：`cmdFK()`:3372 · `readActualEndPose()`:3359 · `ArmApi_GetStatus()` + `FK_Solve()`

## 5. 批量保存路点 / 设速度 / 设驻留

固件是**逐点**接口，批量 = 软件侧循环发即可，固件不用改：

| 命令 | 作用 |
|---|---|
| `q <n 1~8> <j1..j6>` | 存关节路点（舵机度） |
| `qg <n> <x y z> [pitch]` | 存笛卡尔路点（固件先 IK + FK 回代校验，失败拒存） |
| `qv <n> <v>` | 第 n 段速度 5~300 deg/s |
| `qd <n> <ms>` | 第 n 点驻留 0~60000 ms |
| `QL n r v` / `QLC n r v` | 执行循环（r=0 无限） |

⚠ 固件路点表上限 **8 点**（`MULTI_POINT_MAX`）；下标 1-based。

## 7. 完善校准功能

| 步骤 | 命令 |
|---|---|
| 扫描总线 | `n`（J1~J3 = Bus A，J4~J6 = Bus B） |
| 初始化 | `i` 全部 / `i J` 单轴 |
| 一键置中 | `M a` 全部 / `M <0~5>` 单轴 —— 把**当前姿态**写成舵机中位 2048（写 EEPROM，会释放扭矩） |
| 两阶段限位校准 | `c` → Phase1 摆官方 Home（L 形）按 `0` 记零点；Phase2 手转各轴到极限自动跟踪 MIN/MAX → `s` 存盘、`q` 退出 |
| 查/设限位 | `L` 查看全部 / `L J min max` 设置（deg） |
| 单轴读数 | `p J`（raw / servo / rel-home 三值） |
| 扭矩 | `t J 0/1` |

详细需求、注意事项与现场步骤见 `docs/上位机校准功能需求说明_2026-09-16.md`。
