# 上位机 4 个算法验证模块联调说明

> 适用固件：桌面工程当前版本（CAN1=PA11/PA12, APROTO v1, arm_params 16 项）  
> 日期：2026-08-13

## 重要前提

当前固件**没有为这 4 个模块提供独立的“验证”命令**。上位机里的“验证 IK-CCD / 验证 S 曲线 / 验证重力补偿 / 验证 PID”按钮，**需要由上位机自己组合多条已有命令、采集回传数据、做对比判断**。

也就是说：下位机只负责“参数读写 + 运动 + 状态反馈”，验证逻辑（算误差、画曲线、判收敛）在上位机里做。

## 模块 1：IK-CCD 逆运动学

### 上位机界面字段 → 固件参数 ID 映射

| UI 字段 | 参数 ID | 参数名 | 默认值 | 范围 |
|---------|---------|--------|--------|------|
| ik.converge_mm | 1 | `AP_IK_CONVERGE_MM` | 0.5 mm | 0.1 ~ 5.0 |
| ik.max_iter | 2 | `AP_IK_MAX_ITER` | 100 次 | 10 ~ 500 |
| ik.fail_mm | 3 | `AP_IK_FAIL_MM` | 1.0 mm | 0.5 ~ 10.0 |
| ik.fk_verify_mm | 4 | `AP_IK_FK_VERIFY_MM` | 5.0 mm | 1.0 ~ 20.0 |

### 读取参数

文本串口：
```text
LP
```

二进制 / CAN：
- `PARAM_READ (0x40)`，payload = `[0x01]` 读 `ik.converge_mm`
- 依次读 1~4

### 写入参数

文本串口：
```text
SP 1 0.5
SP 2 100
SP 3 1.0
SP 4 5.0
```

二进制 / CAN：
- `PARAM_WRITE (0x41)`，payload = `[id, val_i32_3B]`，val 定点 ×1000

### 验证 IK-CCD 的方法

下位机没有“验证 IK”命令，上位机应执行以下流程：

#### 步骤 A：纯 IK 解算验证（不动机械臂）

```text
qg <idx> <x> <y> <z> [pitch]
```

例如：
```text
qg 1 150 0 200 0
```

下位机回复示例：
```text
XYZ point 1 saved: X=150 Y=0 Z=200 mm, Pitch=0 deg
IK: J1=150 J2=130 J3=160 J4=140 J5=150 J6=150 deg
```

**上位机验证点**：
1. 如果回复包含 `"IK failed"` → IK 无解或 FK 验证误差 > `ik.fk_verify_mm`
2. 如果回复了 6 个角度 → 解算成功
3. 用这 6 个角度自己做 FK（或发 `f` 读实际位姿），对比目标 `(x,y,z,pitch)`

#### 步骤 B：实际运动 + FK 回读验证

```text
g 150 0 200 0
```

等机械臂到位后（轮询 `GET_STATUS` 直到 `traj_active=0` 且反馈稳定），再发：

```text
f
```

下位机回复示例：
```text
FK: x=149 y=0 z=201 mm  pitch=0 deg
J1=150 J2=130 J3=160 J4=140 J5=150 J6=150 deg
```

**上位机验证点**：
- 目标位置 vs 实际 FK 位置的误差
- 误差应 < `ik.fk_verify_mm`（默认 5 mm）
- 如果误差过大，说明机械臂结构尺寸、零位偏移或关节限位需要重新标定

#### 步骤 C：批量验证（推荐）

上位机可以预定义一组测试点，循环执行：
1. `qg idx x y z pitch` 解算
2. `g x y z pitch` 运动
3. 等待到位
4. `f` 读实际位姿
5. 计算误差并列表

这等价于你原来文本命令里的 `QL` / 多点定位实验，只是改成笛卡尔空间验证。

## 模块 2：S 曲线轨迹

### 上位机界面字段 → 固件参数 ID 映射

| UI 字段 | 参数 ID | 参数名 | 默认值 | 范围 |
|---------|---------|--------|--------|------|
| sc.tj | 16 | `AP_SC_TJ_S` | 0.15 s | 0.02 ~ 0.50 |
| sc.def_vmax | 17 | `AP_SC_DEF_VMAX` | 30 deg/s | 5 ~ 300 |
| sc.def_accel | 18 | `AP_SC_DEF_ACCEL` | 60 deg/s² | 10 ~ 600 |
| sc.v_min | 19 | `AP_SC_V_MIN` | 5 deg/s | 1 ~ 50 |
| sc.v_max | 20 | `AP_SC_V_MAX` | 300 deg/s | 50 ~ 300 |
| sc.accel_factor | 21 | `AP_SC_ACCEL_FACTOR` | 2.0 | 1.0 ~ 4.0 |

> 注意：你截图里 `sc.tj=0.100`、`sc.def_vmax=20`、`sc.def_accel=30`、`sc.accel_factor=1.000`，说明上位机显示的是当前 RAM 里的值，不是默认值。这是正常的。

### 读取 / 写入

文本：
```text
LP
SP 16 0.1
SP 17 20
SP 18 30
```

二进制：同 PARAM_READ/WRITE，ID=16~21。

### 验证 S 曲线的方法

下位机没有“输出轨迹曲线数据”的功能，上位机验证必须：

#### 方法 A：运动时间验证

1. 让机械臂从 HOME 运动到一个较远位姿，例如：
   ```text
   P 3        // WAVE1
   ```
2. 上位机记录 `g` / `P` / `m` 命令发出时刻
3. 持续轮询 `GET_STATUS`，记录 `traj_active` 从 1 变 0 的时刻
4. 用理论 S 曲线时间做对比：
   - 梯形 / S 曲线的时间可以用距离、v_max、a 估算
   - 如果 `sc.def_vmax` 改小，运动时间应变长
   - 如果 `sc.def_accel` 改小，启动/停止更平缓

#### 方法 B：实时角度采样（推荐）

1. 发送运动命令：`m 100 200 150 150 150 150 30`
2. 运动期间连续发送 `GET_STATUS`（建议 50~100 ms 周期）
3. 解析 `GET_STATUS` 返回的 6 个关节目标角度 / 当前角度
4. 上位机用时间戳画出每个关节的角度-时间曲线，观察是否平滑、无抖动

`GET_STATUS` 返回字段（参见操作文档）：
- 字节 0~11：6 个关节的**当前实际角度**（定点 ×10，deg）
- 字节 12~17：6 个关节的**目标角度**（定点 ×10，deg）
- 字节 20 bit1：`traj_active`（轨迹是否仍在运行）

#### 方法 C：急停测试

1. 发送长距离运动：`P 3`
2. 运动中途发送 `STOP`（文本 `S` 或二进制 `0x11`）
3. 观察机械臂是否平滑减速停止，而不是突然锁死

## 模块 3：重力补偿与自适应修正

### 上位机界面字段 → 固件参数 ID 映射

| UI 字段 | 参数 ID | 参数名 | 默认值 | 范围 |
|---------|---------|--------|--------|------|
| gc.k | 32 | `AP_GC_K` | 0.0 deg/mm | 0 ~ 0.5 |
| corr.enabled | 33 | `AP_CORR_ENABLED` | 1 | 0 / 1 |
| corr.threshold | 34 | `AP_CORR_THRESHOLD` | 2.0 deg | 0.5 ~ 10.0 |
| corr.max_rounds | 35 | `AP_CORR_MAX_ROUNDS` | 10 | 1 ~ 20 |
| corr.gain_j1 ~ j6 | 36~41 | `AP_CORR_GAIN_J1~J6` | 0.2,0.5,0.3,0.2,0.2,0.2 | 0 ~ 0.85 |

### 读取 / 写入

文本：
```text
LP
SP 32 0.05
SP 33 1
SP 34 2.0
```

二进制：PARAM_READ/WRITE，ID=32~41。

> 注意：这 10 个参数都在 `arm_params` 表里，可以用统一 LP/SP 读写。

### 验证重力补偿的方法

#### 测试 1：J2 前馈补偿（gc.k）

1. 先关闭自适应修正，避免干扰：
   ```text
   A e 0
   ```
2. 让机械臂伸到前方水平位置，J2 受重力会下垂：
   ```text
   g 180 0 80 0
   ```
3. 等运动完成后，用 `f` 读实际位姿，记录末端高度 Z
4. 设置重力补偿系数：
   ```text
   SP 32 0.05
   ```
   或文本命令：
   ```text
   G k 0.05
   ```
5. 重新发同样命令 `g 180 0 80 0`
6. 比较两次的末端 Z 坐标：
   - 如果补偿有效，第二次的 Z 更接近目标值 80 mm
   - 如果过补，会高于 80 mm

#### 测试 2：自适应修正（corr.enabled）

1. 开启自适应修正：
   ```text
   A e 1
   SP 34 2.0
   SP 35 10
   ```
2. 让机械臂伸到前方受重力位姿：
   ```text
   g 180 0 80 0
   ```
3. 运动后下位机会自动进入修正状态，串口会输出类似：
   ```text
   Move reached. Adaptive correction starting...
   J2 corr #1: actual=128 tgt=130 -> 131 (err=2, gain=50%)
   J3 corr #1: actual=158 tgt=160 -> 161 (err=2, gain=30%)
   Adaptive correction DONE: all within +/-2 deg (3 rounds)
   ```
4. 上位机验证点：
   - 修正后实际角度是否进入 `corr.threshold`（默认 ±2°）
   - 修正轮数是否不超过 `corr.max_rounds`
   - 比较 `corr.enabled=0` 和 `corr.enabled=1` 的到位精度

#### 测试 3：修正增益灵敏度

修改 `corr.gain_j2` 为不同值（如 0.2 / 0.5 / 0.8），重复测试 2，观察：
- 增益太小 → 修正慢，轮数多
- 增益太大 → 可能振荡，过冲
- 截图中的默认值 0.5 对 J2 是比较合理的

## 模块 4：舵机 PID

### 重要：PID 不在 arm_params 表里

XL320 的 P/I/D 增益**不属于** `arm_params` 统一参数表，因此：

- **不能**用 `PARAM_READ/WRITE (0x40/0x41)` 读写 PID
- **必须**用文本命令 `K / I / D / N`，或后续新增的二进制命令

### 读取当前 PID

文本串口：
```text
G
```

下位机回复包含：
```text
=== Adaptive Correction & PID Status ===
...
PID: P=[16 32 16 16 16 16] I=[4 4 4 4 4 4] D=[12 12 12 12 12 12]
```

或者单独读某关节：
```text
N 1
```
回复：
```text
J1 PID = P:16 I:4 D:12
```

### 写入 PID

单关节全部设置：
```text
N 1 32 0 0
N 2 32 0 0
...
```

单独改 P/I/D：
```text
K 1 32    // J1 P=32
I 1 4     // J1 I=4
D 1 12    // J1 D=12
```

### 验证 PID 的方法

#### 测试 1：单关节阶跃响应

1. 选择一个关节（建议 J2，负载最大）
2. 先读当前位置：
   ```text
   p 1
   ```
3. 发一个角度阶跃命令：
   ```text
   a 2 120
   ```
4. 连续读位置（可用 `pv 100` 每 100ms 反馈一次）
5. 上位机画出角度-时间曲线，观察：
   - 超调量
   - 稳定时间
   - 稳态误差
   - 是否振荡

#### 测试 2：P 增益影响

1. 设置不同 P 值：
   ```text
   N 2 16 4 12
   N 2 32 4 12
   N 2 48 4 12
   ```
2. 每次设置后做阶跃测试
3. 规律：
   - P 小 → 响应慢、稳态误差大
   - P 大 → 响应快、可能振荡

#### 测试 3：D 增益影响

固定 P/I，改变 D：
```text
N 2 32 4 0
N 2 32 4 12
N 2 32 4 24
```

规律：
- D 小 → 容易振荡
- D 大 → 阻尼增加，但响应变慢

#### 测试 4：稳态误差 / I 增益

如果机械臂到位后仍有 persistent 误差（比如 J2 下垂），增加 I：
```text
N 2 32 8 12
```
观察稳态误差是否被消除。

## 上位机“验证”按钮建议实现

### IK-CCD 验证按钮

```python
def verify_ik(x, y, z, pitch=0):
    # 1. 读取当前参数（可选）
    send("LP")
    
    # 2. 解算
    send(f"qg 1 {x} {y} {z} {pitch}")
    parse_ik_solution()
    
    # 3. 实际运动
    send(f"g {x} {y} {z} {pitch}")
    wait_for_motion_done()
    
    # 4. 读实际位姿
    send("f")
    actual = parse_fk_output()
    
    # 5. 计算误差
    error = sqrt((actual.x-x)**2 + (actual.y-y)**2 + (actual.z-z)**2)
    return error < fk_verify_mm
```

### S 曲线验证按钮

```python
def verify_scurve(target_pose, v_max):
    # 1. 设置 S 曲线参数
    send(f"SP 17 {v_max}")
    
    # 2. 启动实时反馈
    send("pv 50")  # 50ms 周期
    
    # 3. 发送运动命令
    send("P 3")  # 或 m/g
    
    # 4. 连续采集直到 traj_active=0
    record_joint_angles()
    
    # 5. 上位机画角度-速度-加速度曲线
    plot_scurve()
```

### 重力补偿验证按钮

```python
def verify_gravity():
    # 关闭自适应修正，单独看 gc.k
    send("A e 0")
    
    for k in [0.0, 0.05, 0.1, 0.2]:
        send(f"SP 32 {k}")
        send("g 180 0 80 0")
        wait_for_done()
        send("f")
        z = parse_fk_z()
        record(k, z)
    
    # 再开启自适应修正对比
    send("A e 1")
    send("g 180 0 80 0")
    wait_for_done_with_correction()
    send("f")
    z_corr = parse_fk_z()
```

### PID 验证按钮

```python
def verify_pid(joint, p, i, d):
    send(f"N {joint} {p} {i} {d}")
    
    # 阶跃响应
    start_pos = read_position(joint)
    target = start_pos + 30
    send(f"a {joint} {target}")
    
    send(f"pv 50")
    record_until_settled(joint, target)
    plot_response()
```

## 关键注意事项

1. **PID 不能用二进制 PARAM_WRITE 写**：当前固件的二进制 0x41 只支持 `arm_params` 表里的 16 项参数。PID 必须通过文本 `K/I/D/N` 或 `F`/`X` 操作。

2. **Flash 保存**：所有参数修改后如果要断电保持，必须发文本命令：
   ```text
   F
   ```
   当前二进制/CAN 协议没有 SAVE_CONFIG 命令。

3. **参数写入即时生效**：`SP` / `PARAM_WRITE` 改的是 RAM，下一次运动立即生效，不需要重启。

4. **重力补偿 gc.k 和自适应修正的关系**：
   - `gc.k` 是运动过程中的**前馈补偿**
   - `corr.enabled` 是运动结束后的**反馈修正**
   - 两者可以独立开关

5. **IK 验证前确保机械臂已经标定**：即 `arm_config.json` 中的连杆尺寸、零位偏移、关节限位与真实机械臂一致。否则 IK 解算出的角度会让机械臂去错的位置。
