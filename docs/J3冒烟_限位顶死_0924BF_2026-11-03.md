# J3 冒烟事故复盘 — 限位"顶死"堵转（0924BF，2026-11-03）

## 1. 现场

- 遥操时 **从臂 J3 不跟随、不动**。
- 手轻拖 J3 → **冒出白烟 + 焦味**。

## 2. 直接原因：0924BE 的 clamp 修复把"跳变"换成了"顶死"

| 版本 | 目标略微超出上限时 | 物理后果 |
|---|---|---|
| 0924BD（旧，单向距离） | 夹到**对面的 min**（差 ~195°） | J3 反向猛窜 — 吓人，但**不发热** |
| 0924BE（我改的，双向最短） | 夹到**本侧 mx**（挡块位置） | J3 贴着挡块不动 — **安静，但满力矩堵转** |

**这是本次事故的根因，责任在 0924BE 的改动。**

关键机理：`mx` 是 Phase2 **手推顶死挡块**测出来的极值。舵机受齿隙、结构柔性、
金属舵盘弹性限制，**实际根本到不了那个 raw**。目标一旦钳在 `mx` 上：

```
误差 = |mx - 真实可达位置| 恒 > 0
  ⇒ 位置环积分饱和
  ⇒ 电流持续拉满 → 线圈过热 → 冒烟
```

"不动"和"冒烟"是同一件事的两面：舵机一直在全力顶挡块，只是位移看不出来。

## 3. 次要隐患（本次一并修掉）

### 3.1 流控缺"未校准"保护（既有 bug，非本轮引入）

- `JOINT_MIN_RAW[]` / `JOINT_MAX_RAW[]` 默认 **全 0**。
- `raw_in_range(raw, 0, 0)` → `span == 0` → **return 0**（永不在范围内）。
- `clamp_raw(want, 0, 0)` → 恒返回 `mn = 0` → **六轴目标全变 raw 0（0°）**。
- `clamp_all_angles()` 一直有 `mn==0 && mx==0 → continue` 保护，
  **但 `cmdStreamJoints()` 漏了这层** ⇒ 限位一旦没标定，遥操直接让六轴全速撞 0°。

### 3.2 无"持续顶限位"告警

`lk` 只给累计被夹帧数，看不出"已经连续顶死 5 秒"。操作者没有任何早期信号。

## 4. 0924BF 修复

| # | 修改点 | 内容 |
|---|---|---|
| A | `STREAM_CLAMP_MARGIN_RAW 28U`（≈2.5°） | **边界安全带**：不论目标是否被 clamp，只要距 mn/mx 不足 28 raw 就往弧内推，让舵机停在挡块**前**几度，误差≈0、出力极小。行程过窄（span ≤ 2×MARGIN）时不推，避免推穿到对面 |
| B | `cmdStreamJoints()` 未校准保护 | `mn==0 && mx==0` 时**不夹**（直接放行 `want`），与 `clamp_all_angles()` 对齐 |
| C | `stream_clamp_streak` 告警 | 连续被夹 200 帧（≈5s@40Hz）打印 `[STALL] limit held N frames -- release stick`，之后每翻倍再报 |

## 5. 构建

```
make LINK=net BUS_PP=1     # 用户板(126 在位)
```

- 终版 `fw0924bf_pp.bin` **270,328 B**，md5 **`13a2fb242ba8166618963cdec0fe77ea`**
- text 269,236 / data 1,084 / bss 96,700（栈余量 ~16KB，正常）
- 只编了用户板对应的 `LINK=net BUS_PP=1`（126 在位）；OD / BUS_ONE / BOTH / master 未重编

### 4.1 数值验证抓到的初版漏洞（`tools/verify_clamp_fix.py`）

初版 A 只在 `raw[j] != want`（即**被 clamp 夹住**）时才内缩。数值验证用真机限位跑出：

```
合法但贴上限 270.6°  →  BF初版 270.6（clamp 不触发，没内缩）→ 距挡块仅 0.4°
```

而 09-28 现场实测 J3 就是 **270.6°**，正好落在这个盲区。也就是说初版装上照旧会顶死。
终版改为**全帧判边界安全带**后，该例被推到 268.6°，距挡块 28 raw。

`python tools/verify_clamp_fix.py` → `RESULT: PASS`（8 组用例含跨 0 弧 / J5 窗口 / 未校准）。
`python tools/check_cprint_len.py` → 无超 255B 的 cprint。

## 6. 硬件处置（⚠ 已冒烟/焦味 ⇒ 禁止再通电）

**冒烟 + 焦味 = 漆包线绝缘已碳化，属不可逆损伤。此时任何"通电测一下"
都会扩大损坏范围**（短路线圈会持续拉垮 5V 母线，连带烧 74HC126、其他舵机的
驱动级，严重时有起火风险）。**不存在"再上电确认一下"这一步。**

正确顺序：

1. **立即断开 12V 与 5V 全部电源**，不要只是按 RESET。
2. **把 J3 从总线上物理摘除**（拔掉它的两端航插，或把上游线直接跨接到下游），
   让其余 5 颗不再与短路的 J3 挂在同一条母线上。
3. 检查 J3 的线材/插头有无熔痕、铜芯外露、相邻线粘连。
4. 检查 74HC126、电源模块、总线插座有无焦痕或异味（连带损伤判据）。
5. 拆下的 J3 单独存放，**不要**再接到任何带电系统里。
6. 断电状态下可手转 J3 判断机械部分：顺畅 = 齿轮尚可，卡死 = 齿轮/轴承已损。
   但**机械完好不等于电气完好**，不能据此复用。

### 换舵机后要不要重标定？—— 分情况，不是一律要

`JOINT_MIN_RAW/MAX_RAW` 是**机械挡块**的位置，不是舵机自身参数。所以：

| 情况 | 处理 |
|---|---|
| 同型号舵机、舵盘 zero 对准原 Home 姿态、连杆/挡块未动 | **不必重标定**，旧限位值继续有效，`margin` 按同一挡块计算仍然成立 |
| 换了型号、拆装时动了舵盘或连杆、挡块被撞变形、zero 重新锚过 | 必须 **重设 ID → `zi` 重锚零点 → `c` 校准 + `s` 保存** |

⚠ 唯一要复核的是 `L` 打出来的 J3 上下限是否仍与物理挡块吻合（烧掉的舵机可能
曾把挡块顶变形）。若 `L` 报 76~271 而手推顶死位置明显偏移，才需要重标定。

## 7. 后续建议

- **遥操顶限位是正常操作**，但固件必须保证"顶住时不出力"。A 项只是缓解；
  彻底方案是检测"目标不变 + 位置不动"后把该轴 GoalSpeed 置 0 或降 Torque Limit。
- 主臂侧同理：主臂 J3 顶死限位时不该继续外发超限目标，应在源头削平。
- 总线误码 p≈0.63 未解决（1kΩ→470Ω 上拉），丢读会让"位置不动"的判据失真。
