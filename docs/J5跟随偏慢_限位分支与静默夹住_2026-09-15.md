## 1. 假设是什么，为什么被否掉

**假设**：一端 `calib_zero_raw[4] = 0` 走兜底分支、另一端非 0 走偏移分支
⇒ 两条分支的 rel-home 口径差 90.81° ⇒ 从臂把主臂的 J5 解释错方向。

**实测**（两臂各敲 `zi`，原始数据见主线文档 §0）：

| | A 臂 | B 臂 |
|---|---|---|
| `calib_zero_raw[4]` | 2047 | 2048 |
| `JOINT_MIN_RAW[4]` / `MAX` | `[1014, 2834]` | `[1015, 2835]` |
| 折算 rel-home 窗口 | `[-90.813°, +69.187°]` | `[-90.813°, +69.187°]` |
| **走的哪条分支** | **偏移分支** | **偏移分支** |

**两臂都走偏移分支** ⇒ 窗口**逐位相同**，差值是 **0.000°**（不是 90.81°）。
⇒ "主臂吐 rel-home、从臂按自己的零点解释、语义差 90.8°"这条链路**不存在**。

（原因：rel-home 窗口 = `(zero+offset)·360/4095 − zero·360/4095` = `offset·360/4095`
—— **`zero` 被整项减掉**，所以只要两臂同走偏移分支，窗口必然逐位相同。）
