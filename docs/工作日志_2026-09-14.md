## 3. 今天定稿的结论（不要再回头翻）

1. **"地弹"结论彻底作废。** 两条支撑证据全部失效：① 读失败 ⇒ 整帧不发（不是噪声消失）；
   ② 所有旧自环数据是在"跳线 + 链路同插"的污染布置下测的。
2. **自环场景下波特率失配物理上不可能**（同 MCU / 同外设 / 同 `BRR`）。几厘米杜邦 + 推挽本该 `NE≈0`。
3. **`HAL_UART_Transmit` 返回 OK 与线通不通无关。**
4. **`stream frames: 0` 且 `rejects` 涨 ≠ 线没通**，而是"收到完整帧但都不是合法命令"，真原因看 `NACK sent err=`。
5. **量级论证必须用固件自己打的 `rate:` 时间戳算**，不能凭"感觉跑了几十秒"（今天已因此撤回一次）。
6. **单次采样不是测量**：出现物理上不可能的读数时，先怀疑**判据/工具**，不要编硬件故事。
7. **引脚一律以 `.ioc` 为准**（今天这个坑又踩了一次：CAN 凭印象写 PA11/PA12，`.ioc` 实为 PB8/PB9）。
8. **任何编译开关都要进 `BUILD_DIR` 后缀**（`BAUD`/`LINK`/`CANPIN`），否则会拷出"假固件"。
9. **CAN 的 `lec=3` 是硬结论**：ACK 由接收方硬件主动驱显性，线上有两个活节点就必然出现。
   `lec=3 + rec=0` ⇒ 发送方从没被第二个节点看见，范围只剩"模块没工作 / 线断接反 / 引脚没接上"。
10. **要有显式停止条件**：① 同板自环失败 ② 该路径固件已逐行读完且干净 ③ 某只脚过不了自己的输出驱动自检
    —— 满足其一就别再"再试一次"，改走"换路线 + 报价"的菜单式决策。

## 6. 明天现场怎么做（★ 今天已有固件，需重新烧）

```
0) 烧录（BOOT0 拉高 → RESET → 烧 → BOOT0 拉回低 → RESET）
     make flash ROLE=master LINK=can PORT=COM11     # 主臂
     make flash           LINK=can PORT=COM11       # 从臂
   （若只有 PA11/PA12 引出，加 CANPIN=pa；两块板必须同一组）

1) 两块板各敲  e      → 应看到 "RESULT: PASS - CAN controller OK"（不接总线也能跑）
2) 两块板各敲  cn     → hw init=ok；看 bus pin: MSR.RX=1 还是 0；INAK/SLEEP/BOFF 有无告警
3) 两块板各敲  cp     → ★ 信息量最大：RX 脚 [被外部驱高] 还是 [悬空]
4) 两块板各敲  cz     → "低"的次数 > 0 ?
5) 主臂 mf 0 后，从臂敲  cy 1000  → 有没有跳变?
6) 通链后再：主臂 ms（frames sent 在涨）+ 从臂 cn（"合法好帧"~30/s）→ 摆齐两臂 sf 1
```

**对照结论**

| 现场现象 | 结论 | 动作 |
|---|---|---|
| `cp` RX 显示 `[悬空]` | 模块没上电 / RXD 没通到该脚 | 查 VCC+GND、跳线；或该脚没引出 → 换 `CANPIN=pa` 版 |
| `cp` RX `[被外部驱高]` 但 `cz` 全程无"低" | 模块收得进、发不出 | 查模块 TXD 接线（是否接反）、跳线、器件型号 |
| `cz` 有"低" + 从臂 `cy` 有跳变 | 收发两侧都通 | `ct` 不涨就得换思路，回来一起看 |
| `cz` 无"低" + `cy` 恒高 | 两端模块都没在工作 | 重点查供电与 `5V/3.3V` 跳线 |

**头号嫌疑**：那块「CAN PHY V1」模块的 `电平选择 5V/3.3V` 跳线，必须与 VCC 电压匹配 ——
`TJA1050/SIT1050` 是 5V 器件；`SN65HVD230/VP230/TJA1051T-3/TJA1042T-3` 可 3.3V。
**最确定做法：读模块上 U2 那颗芯片的丝印。**
