# 串口下发操作手册（screen 纯文本控制台）— 2026-09-30

> **适用**：Ubuntu 22.04 上位机 ↔ ArmControl_HAL 固件（串口 USART 恒常通，115200）。
> 本文档只讲**串口下发**；网口操作见《网口下发操作手册》。
> 串口的价值：**保底通道**——固件没开网口/网口挂掉时它永远在；也是查真实 IP、判版本的第一现场。

---

## 1. 操作步骤（按顺序走）

### 步骤 0：安全底线

- 固件**没有看门狗**；`m`/`P` 会让臂真动，第一次动手边留好断电手段。
- **绝不用 `M a`**（=标定向导，松力矩整臂塌下）；老固件别敲 `cx`（同类危险）。
- 按板子上的 **RESET 键**重启（CCM RAM 跨复位保留参数），**不要拔电源**。
- 串口运动同样会**解除 RC 手柄武装**（之后双击 START 或 `rc go on` 恢复）。

### 步骤 1：找到串口设备并授权

```bash
ls /dev/ttyUSB*                          # 一般是 /dev/ttyUSB0（CH340/CP210x）
sudo usermod -aG dialout $USER           # 加组（重新登录一次生效）
# 临时快速法：sudo chmod 666 /dev/ttyUSB0
dmesg | tail                             # 插拔串口线看识别记录（没设备名时用）
```

### 步骤 2：进入控制台

```bash
sudo apt install screen                  # 没装的话
screen /dev/ttyUSB0 115200
# 进入后直接打命令 + 回车（行尾会自动带 \r）
# 退出：Ctrl+A 再按 K，确认 y
```

### 步骤 3：判版本 + 拿真实 IP（第一条必敲）

```
h
```
- 首行 `fw-tag` = **判版本唯一可信**来源（UDP 的 GET_INFO 历史上不同步）。
- 首行 `udp=192.168.7.XXX:5000` = **臂的真实 IP**——网口配置就填这个。

### 步骤 4：看状态（只读）

```
s      ← 六轴状态表（角度/ID/是否在动/温度）
zi     ← 零点自检（怀疑零点被污染时先敲它）
```

### 步骤 5：第一次运动（回中位，低速）

```
m 180 180 180 180 180 180 15
```
- 六轴到舵机度 180（中位），末位 15=速度 15 deg/s。
- 单轴点动：`m 185 180 180 180 180 180 15`（J1 +5°，舵机度域）。

### 步骤 6：回折叠收纳位（收工）

```
P 0
```
- 编号：**0=HOME(真折叠收纳位)** 1=FOLD(备用收拢) 2=READY 3/4=WAVE 演示。
- 轨迹规划式运动（非直达）；E-STOP 或有回放进行中会被拒绝。

### 步骤 7：退出

`Ctrl+A` → `K` → `y`。不退出直接拔线偶尔会把 tty 锁住，用完规范退出。

## 2. 命令参考（固件原生控制台）

> 这些命令**网口同样能发**：`armctl --uri $ARM text --cmd "<命令>"`，回显逐字相同。

### 2.1 观测类（只读，随便敲）

| 命令 | 作用 | 注释 |
|---|---|---|
| `h` | 版本/帮助 | 首行 fw-tag 判版本 + `udp=` 拿 IP；长回显会刷屏，属正常 |
| `s` | 六轴状态表 | 角度/ID/Moving/温度；只读 |
| `zi` | 零点自检 | 打印 calib_zero_raw / SERVO_OFFSET / JOINT_MIN/MAX_RAW；有轴为 0 = 未校准 |
| `L` | **算法参数表**（LP/SP 域 24 项） | 另含 RunLog 级别与世界偏移；**不是限位表** |
| `pv` / `pf <ms>` | 实时角度流 / 实时位姿流 | `pv 0` 停止；调试连续运动时用 |
| `link` | 链路查询 | 看 active= 和 saved= |
| `rc` / `rc keys` / `rc keysw 30` | 手柄状态 / 按键可视化 / 实时监视 | 配对、验遥控链路用 |
| `rc diag` | PS2 接线诊断 | 三档字节间隔；**全 FF = 没看到 CS/CLK（接线问题）** |

### 2.2 运动类

| 命令 | 作用 | 注释 |
|---|---|---|
| `m <a1>~<a6> [speed]` | 六轴到**舵机度** | 0~300；speed 默认 30 deg/s；`m 180 180 180 180 180 180 15` = 回中位标准姿势 |
| `m 185 180 ... 15` | 单轴点动 | 改一个轴的数即可；±5° 一档试探 |
| `P <0~4>` | 预定义位姿 | 0=HOME(**真折叠收纳位**) 1=FOLD(备用) 2=READY 3/4=演示；轨迹规划式 |
| `g <x> <y> <z> [pitch]` | IK 走到 XYZ(mm) | 走笛卡尔；pitch 默认 0=朝上；先 `g` 只解算的运动版，失败会回原因 |
| `t <J> <0\|1>` | 单轴力矩开关 | ⚠ `t J 0` = 松该轴力矩，臂会垂 |
| `S` | 全部运动停止 | 循环/摆动进行中先敲它 |

### 2.3 参数 / 校准类

| 命令 | 作用 | 注释 |
|---|---|---|
| `SP <id> <value>` | 设算法参数（RAM） | id 表看 `L`；**超范围静默钳制**，设完回读 |
| `F` | 参数落盘 Flash | 重启保持；标定/改参后必敲 |
| `zf <mm>` / `zf clear` | 设桌面下限 / 清除 | 爪尖最低离桌 mm；存 flash 区 F，设值即自动存 |
| `zr [save]` | Home 零点复位 | ⚠ 六轴基准全部回出厂中位；`zr save` 写 Flash |
| `link net` → `link save` → RESET | 切网口三连 | **必须按 RESET**（别断电）才生效 |
| `rc go on` / `rc go off` | 手柄武装开关 | 等同双击 START；被 PC 运动解除后用它恢复 |
| `rc map [save\|def]` | 键位映射 | 存 flash 区 E |

### 2.4 危险命令（没读懂《网口指令大全》§15.5 前不要敲）

| 命令 | 后果 |
|---|---|
| `M a` | ⚠⚠ = 标定向导：六轴写 raw 2048 居中，**松力矩、改变量纲基准、不可逆** |
| `c`（校准向导） | 交互式 `for(;;)` 等人在**本机串口**敲 0/s/q——**只能串口用**，网口进=死锁 |
| `i` | cmdInit()：Torque ON + 重设 joint mode，臂会**当场绷紧** |
| `cx` 系 | CAN 取证/切换类，网口构建下被固件拦截；老固件上会进校准向导 |

## 3. 高频坑速查

| 现象 | 原因 → 解法 |
|---|---|
| 敲了没反应 | 手搓脚本发串口时行尾必须 `\r`（screen 手打无此问题） |
| 改了 link 不生效 | 三连没走完：`link net` → `link save` → **按 RESET** |
| 参数重启就丢 | 改完没敲 `F` 落盘；`zf`/`rc map`/`link save` 例外（各自自动存） |
| 找不到 ttyUSB0 | `dmesg \| tail` 看识别；dialout 组没生效就重新登录 |
| NoMachine 里串口卡死 | 换命令行 SSH 进去测，图形会话偶尔锁设备 |
| 长命令刷屏停不下来 | `pv 0` / `rc keysw 0` / `TM` 系列记得关；`Ctrl+A` `K` 强退兜底 |

## 4. 回传样例（真机格式逐字段注解）

> 以下格式**逐字取自固件 `cprint` 格式串**（`Core/Src/main.c`），非手编、非模拟器。

### 4.1 `h`（首两行）

```
  fw-tag ARM-NET-0924AV phy=LAN8720A(RMII)  udp=192.168.7.120:5000  build=LINK=net  txpins=PG11/PG13/PG14
  fix=net-udp,nocancmds,txpins-pg,mdc-div102,...（编译修正项长串，换行继续）
```

| 字段 | 用途 |
|---|---|
| `fw-tag` | **判版本唯一可信**（UDP GET_INFO 的 fw_tag 历史上多次不同步） |
| `phy` | 网口 PHY 型号；`NOT found` ⇒ 网线/PHY 问题 |
| `udp=` | **臂的真实 IP:端口**——网口配置就填这个 |
| `build=` | 当前激活链路（net/both 才通 UDP） |

### 4.2 `s`（六轴状态表）

```
  +----+----+-------+--------+------+
  |Jnt | ID | Angle | Moving | Temp |
  +----+----+-------+--------+------+
  | J1 | 1  | 180.0 |   -    |  42C |
  | J2 | 2  | 180.0 |   -    |  41C |
  ...（六行，一轴一行）
  +----+----+-------+--------+------+
```

- `Angle` 舵机度；`Moving` +/‑=是否在动；`Temp` 舵机温度（>60C 该查负载了）。
- 某轴整行读失败时该行数值缺省——重敲一次 `s`，别把空值当 0。

### 4.3 `P 0`（回折叠位）

```
  Pose 0 (HOME): 213 143 232 139 180 180
  Move started.
```

- 第一行 = `cmdPose` 回显：位姿编号、名字、六轴目标舵机度（这组是折叠收纳位的实测值）。
- `Move started.` = 轨迹已起步。之后用 `s` 确认到位（err/ACK ≠ 动了）。
- 被拒时的样子：`折叠位: E-STOP 激活, 拒绝` / `折叠位: 有运动/回放进行中, 拒绝`。

### 4.4 `m`（用法行与钳制行）

```
  Usage: m <a1> <a2> <a3> <a4> <a5> <a6> [speed]
  Angles in degrees (0~300), speed in deg/s (default=30)
```

参数给错时的回显如上。目标超 0~300 时打钳制行：

```
  J3: 320 -> 300 deg (raw 4255 -> 4095 limit)
```
- 🟡 **被钳制的样子**（正常防护）：请求 320° 被软拦到 300°——改小目标，不是故障。

### 4.5 `zi`（零点自检，节选）

```
  ===== zi: Home 零点 / IK 限位 状态 =====
  calib_zero_raw (官方 Home 姿态 raw; 0=未校准 ⇒ 出厂中位 180°)
     [2048 2048 2048 2048 2048 2048]
  SERVO_OFFSET (IK 关节 0 位, 度)
     [180.0 180.0 180.0 180.0 180.0 180.0]
  JOINT_MIN_RAW [...]
  JOINT_MAX_RAW [...]
```

- `calib_zero_raw` 有轴为 0 = 该轴**未校准**，量纲基准是脆的（IK/限位都不可信）。
- 全 2048 = 出厂中位；做过标定 + `F` 后才是实测 Home raw。
