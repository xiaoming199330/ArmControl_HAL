## 0. 一句话

网口只跑**二进制协议**，运动只有一条路：**`MOVE_JOINTS (0x10)`**。
**按 S0 → S7 顺序做，一步不过不要跳到下一步。** 每步都写了"过 / 不过"的判据。

## 1. 开工前置（三件，缺一不可）

| # | 事项 | 怎么做 | 判据 |
|---|---|---|---|
| ① | **物理安全** | 清空臂的扫过区（半径 ≥ 臂全长）；人不在扫过区；**手边上就是电源开关/急停** | — |
| ② | **隔离主从** | 本板是**从臂**，上电默认 `sf 1`（跟随主臂流帧）。**若对端主臂在发流，你的轨迹会被流帧盖掉**（现象是"ACK 了却不动 / 乱动"）⇒ 先在 **COM11** 敲 `sf 0` | `sf` 回显当前状态 |
| ③ | **零点自检** | COM11 敲 `zi` | 未校准 = 全 0；已校准 ≈ `2048×6`。**被污染则 IK 限位整体错位**（典型症状"以前能到、现在报 limit"） |

> ⚠ 本构建**已显式拦掉** `cx cp cy cz cw ps can` 与 `mg mp mo ml`：
> 前三者会把 **PB12/PB13** 重配成 CAN2 —— 那正是 **ETH 的 RXD1/TXD1**（敲一次网口就死）；
> 后四者会把 **PA0/PA1** 还原成 UART4 —— PA1 正是 **ETH_REF_CLK**。**别试图绕过。**
> ⚠ `nt` 量测期间 PA1 会短暂离开 ETH ⇒ **跑完先按 RESET**，否则表现为"网口突然不通"。
> ⚠ 文本命令走 **COM11 (115200)**，网口**不认**文本命令。

## 2. 关节限位（标称值，舵机度）

| 轴 | 含义 | min | max | 中位 | 首测风险 |
|---|---|---|---|---|---|
| J1 | 底座旋转 | 0 | 360 | 180 | 整臂扫过 ⇒ **需要最大净空，最后测** |
| J2 | 大臂 | 58 | 264 | 180 | 重力矩最大 ⇒ **别当第一个** |
| J3 | 小臂 | 10 | 177 | 180 | 靠近上限易撞底座/立柱 |
| J4 | 腕俯仰 | 83 | 289 | 180 | 中 |
| J5 | 腕旋转 | 180 | 340 | 180 | 中 |
| J6 | **夹爪开合** | 0 | 360 | 180 | **首测首选**（夹爪开合不改变末端位置，位移最小） |

> 上表是**标称显示值**；**权威限位**来自校准 raw 限位（`zi` 可看，`c` 校准写入）。

```powershell
# ---- PowerShell（想指定隔离解释器时）----
# ①等号两边不许有空格  ②变量当命令调用要加 &  ③路径用反斜杠
$PY = "C:\Users\Administrator\.workbuddy\binaries\python\envs\default\Scripts\python.exe"

```

| 症状 | 原因 | 修法 |
|---|---|---|
| `无法将"PY=/c/..."项识别为 cmdlet` | 用了 bash 的 `变量=值` 且 `=` 两边带空格 | 改 `$PY = "C:\..."`（**无空格**） |
| `意外的标记"tools/arm_net_host.py"` | PowerShell 里变量名不是命令，需调用符 | 改 `& $PY tools/...` |
| 路径找不到 | `/c/...` 是 Git Bash 写法 | PowerShell 用 `C:\...` |

| 命令 | 作用 | 为什么需要 |
|---|---|---|
| `--watch N [--gap s]` | 连读 N 次状态，统计丢包 / 时延 / `read_ok` / E-Stop | 只读一次看不出"偶发读失败" |
| `--fk` | 正解查询 `0x21 → 0xA1` | 验证 FK 链路，与 `--status` 互为对照 |
| `--torque J EN` | 力矩开关 `0x12`，`J = all \| 0..5` | 松/抱闸；排查"不动是不是没上力矩" |
| **`--delta J1..J6`** | **★相对微动**：先读当前角，再加增量 | 绝对角要自己算，且**超限会被静默钳制** ⇒ **点动一律用它** |
| `--gap` | `--watch` 每次间隔（默认 0.05 s） | |

## 4. 分级步骤

### S0 先验急停（**机器人不动**）

```bash
$PY tools/arm_net_host.py --ping          # ✅ PING: proto_ver=1 run_id=…
$PY tools/arm_net_host.py --stop          # ✅ STOP err=0
```

然后**物理按下 E-Stop**：

```bash
$PY tools/arm_net_host.py --status        # 应显示 E-Stop=True
$PY tools/arm_net_host.py --delta 0 0 0 0 0 1 --speed 3   # 应被拒: err=5
```

**松开**急停 → `--status` 应立刻回到 `E-Stop=False`。

> `IsEStop()` = 实时读 **PE11**（低有效），**不自锁** ⇒ 松开即恢复，不需要"重新上电/复位"。
> 运动中按急停 ⇒ 固件会 `Trajectory_Stop()` 并打印 `E-STOP! Trajectory aborted.`

**判据**：`--stop` 回 `err=0`；E-Stop 按下时状态位翻转且运动被拒（`err=5`）。**两项都过才继续。**

---

### S1 只读链路（不动机器人）

```bash
$PY tools/arm_net_host.py --watch 30      # ok=30 fail=0 read_ok_FAIL=0 estop=0
$PY tools/arm_net_host.py --param-count   # 参数个数 = 24
$PY tools/arm_net_host.py --fk            # read_ok=1, 位姿与 --status 一致
```

板侧（COM11）敲 `nx`：`crc err=0`、`tx err=0`，`rx/tx` 在涨。

**判据**：0 丢包、`read_ok` 全 1、参数个数 = 24。基线（0920N/O）实测 avg ≈ 11.8 ms。

---

### S2 单轴直读（绕开网口，用串口交叉验证）

COM11：

```
s        → 6 轴 raw/目标/负载/温度/硬件错误, 每轴 error 应为 0
p 5      → J6 当前角（应与 --status 的第 6 个数一致）
```

**判据**：两处读数一致；无硬件错误；温度正常；负载不是持续高值。

---

### S3 最小动作（**只动 J6，+2°**）

```bash
$PY tools/arm_net_host.py --status                              # 记下当前 6 角
$PY tools/arm_net_host.py --delta 0 0 0 0 0 2 --speed 5         # ★首次运动
$PY tools/arm_net_host.py --status                              # 看 J6 是否 ≈ +2
```

想在运动过程中看实时数据，COM11 可敲 `pf 200`（末端位姿流）或 `pv 200`（六轴角度流）。

**判据**：`✅ 已接受 err=0`；`--status` 的 J6 变化 ≈ +2°；**X/Y/Z 几乎不变**（转的是末端轴）。
⚠ 若**方向**与预期相反，先记下来，不要当场连续反向试探 —— 先用 `pf` 看清是哪个符号。

---

### S4 逐轴单点（**一次只动一个轴**）

依"位移从小到大"的顺序，每动一次就回读一次：

```bash
$PY tools/arm_net_host.py --delta 0 0 0 0 3 0 --speed 5     # J5 +3
$PY tools/arm_net_host.py --delta 0 0 0 3 0 0 --speed 5     # J4 +3
$PY tools/arm_net_host.py --delta 0 0 3 0 0 0 --speed 5     # J3 +3
$PY tools/arm_net_host.py --delta 0 2 0 0 0 0 --speed 5     # J2 +2  ← 重力矩最大, 慢
$PY tools/arm_net_host.py --delta 5 0 0 0 0 0 --speed 5     # J1 +5  ← 最后, 净空最大
```

**每步判据**：`err=0`；`--status` 只有那一个轴变了；`read_ok` 仍为 1。
任何一个轴报 `err=4(LIMIT)` ⇒ 增量减半或反向，**不要靠加大速度硬推**。

---

### S5 回原位 / 回零

```bash
# 用反向 delta 原路退回（最安全，全程相对）
$PY tools/arm_net_host.py --delta -5 0 0 0 0 0 --speed 5
...
# 或此时"当前角"已知, 用绝对角一次回位
$PY tools/arm_net_host.py --move 180 180 180 180 180 180 --speed 10
```

> `--move` 是**绝对角**：只有在你**已经用 `--status` 核对过当前角**之后再用（见 §5 第 5 条）。
> COM11 的 `z J` 是**逐轴回 calib 0 位**，会走到工作限位边界，**比回中位更激进，慎用**。

---

### S6 长稳 & 计数器对拍

```bash
$PY tools/arm_net_host.py --watch 100 --gap 0.05
```

板侧 `nx`：`udp cmd`、`crc err`、`tx err` 应长期为 0；`rx/tx` 与上位机的请求/应答次数对得上。

**判据**：100 次 0 丢包；`read_ok_FAIL=0`；`estop=0`。

---

### S7 上高频流（最后）

* 高频关节流走 `0x13 STREAM_JOINTS`（上位机暂未内置，需要时我再加 `--stream-hz`）；
* 这段时间优先用 COM11 的 `pv 200` / `pf 200` / `tm 200` 观察；
  `tm` 能看 **负载/温度/电流/电压/速度** —— 连续运动时的健康度就靠它。
* 频率高了要回头看 S6 的计数器，**`crc err` 一旦非 0 就退回去降频**。

## 5. `MOVE_JOINTS` 内部到底做了什么（为什么这样测是安全的）

`cmdMove()`（`Core/Src/main.c:1556`）的固定动作，按顺序：

1. （`ma` 门是**主臂构建**才有 —— 本板是 **slave**，**没有这道门**，命令直接生效）；
2. 取消 `swing` / 待执行的修正；
3. **退出流模式**（`cmdStreamExit`）—— 轨迹与流帧不能并存（否则总线互抢，表现为抖动/顿挫）；
4. **E-Stop 检查** ⇒ 生效则拒绝并打印；
5. **把目标钳到安全限位**（`clamp_all_angles`）—— ⚠ **是"静默钳制 + 一条 WARNING"，不是报错**；
6. **读起点姿态**（多采样多数表决 + 重试；**读不到就中止本次运动**，绝不用目标值兜底 —— 否则会规划出一条假轨迹）；
7. **自动给 6 轴上力矩**；
8. 规划 S 曲线并执行；到位后由板侧发 `TRAJ_DONE` 事件。

**三个直接推论：**

1. **不需要手动上力矩**（但 `--torque` 仍有用：要把臂松开手拖时用）；
2. **目标超限不会报错，只会被钳** ⇒ **绝对角 `--move` 必须先 `--status` 核对当前角**；
3. **起点读不到会安全中止** ⇒ 这时别反复重试掩盖总线问题，去查 ID/接线/供电。

## 6. 错误码（`Core/Inc/arm_control_api.h`）

| 码 | 名 | 含义 | 现场对策 |
|---|---|---|---|
| 0 | `OK` | 已接受，运动已启动 | — |
| 1 | `PARAM` | 长度/范围/ID 非法 | 查参数个数与取值 |
| 2 | `CRC` | 帧 CRC 校验失败 | 线上干扰 / 工具 bug（先 `--selftest` 自证） |
| 3 | `UNREACH` | IK-CCD 不可达 / 不收敛 | 仅 `MOVE_CART` 会遇到 |
| 4 | `LIMIT` | 限位 / 桌面 / 立柱 / 跳变被拒 | **目标改小或反向** |
| 5 | **`ESTOP`** | 急停生效，禁止运动 | **松开 PE11 急停** |
| 6 | `FK_VERIFY` | IK 解 FK 回代超差 | 标定/参数问题 |
| 7 | `READ` | 舵机总线读取失败 | 查总线/ID/供电 |

## 7. 卡点与对策

| 症状 | 先查（按序） |
|---|---|
| `ACK err=0` 但**臂不动** | ①从臂 `sf 1` 且在跟随 ⇒ `sf 0`；②`--torque all 1`；③`--status` 看 `traj` 是否长期 1（轨迹在跑而舵机不动 = 总线/供电） |
| `--delta` 报 `err=4` | 目标被限位/桌面/立柱拒 ⇒ 增量减半或反向 |
| 某轴 `----` 或 `read_ok=False` | `--watch` 看是否连续失败；连续失败查 ID / 接线 / 供电（偶发单次是总线丢帧） |
| E-Stop 松开后仍不动 | E-Stop **不自锁** ⇒ 松开即恢复；若仍不动查上一条 ①②③ |
| 运动一段时间后**网口不通** | 是不是敲了 `nt`？`nt` 期间 PA1 离开 ETH ⇒ **按 RESET** |
| 越走越偏 / 报 `J4 limit` | COM11 `zi` 看 **Home 零点**是否被污染（`zr save` 可复位） |

## 9. 红线（本阶段专用）

1. **绝对角是"盲发"**：`clamp_all_angles` 会静默钳制 ⇒ 绝对角前必须 `--status`；点动一律 `--delta`。
2. **一次只动一个轴、只动 2~5°**，看着它动完再动下一个。
3. **速度首测 5 deg/s 以内**；确认无误再逐步加。
4. **E-Stop 不是锁存**：松开就恢复，所以"松开后手离开急停"这件事本身就是风险 ⇒ 人别停在扫过区。
5. **别碰 `cx/cp/cy/cz/cw/ps/can` 与 `mg/mp/mo/ml`**（会掐网口 / 掐 REF_CLK）。
6. `nt` 之后先 RESET。
7. 每阶段都把 `nx` 的 `rx/tx`、`crc err`、`tx err` 记一笔 —— 网口的健康度只看这三个数。
