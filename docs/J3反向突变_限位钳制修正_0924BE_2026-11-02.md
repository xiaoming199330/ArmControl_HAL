# 遥操 J3"反向突变"根因：clamp_raw() 越限夹到对面边界（0924BE 修正）

日期：2026-11-02　|　影响构建：所有含限位钳制的构建（即全部）　|　修复版本：**0924BE / 1030E**

## 现象

遥操（PC teleop.py，主臂 leader → 从臂 follower）正常跟踪没问题；**把主臂 J3 往下顶死限位时，从臂 J3 瞬间反向打到对边限位**。

现场快照（GET_STATUS，舵机度）：

| 臂 | J1 | J2 | J3 | J4 | J5 | J6 |
|---|---|---|---|---|---|---|
| 主臂 leader | 177.1 | 71.4 | **271.4** | 199.1 | 185.4 | 180.7 |
| 从臂 follower | 176.6 | 75.5 | **76.1** | 199.2 | 185.2 | 180.9 |

只有 J3 差 195.3°（≈ J3 全行程 194.99°），其余 5 轴差 ≤4.1°。

## 两个候选理论的数字裁决

| 理论 | 预测从臂 J3 | 与实测 76.1° 差 | 结论 |
|---|---|---|---|
| 镜像映射（另一 AI 建议 dir=-1） | 180−91.4 = **88.6°** | **12.5°**（无法解释，只能归为"残留帧"） | ❌ |
| **clamp_raw 越限夹到对面边界** | 夹到 min = **76.0°** | **0.1°**（编码器噪声量级） | ✅ |

若真是机械镜像，J3 平时遥操就该反向走——但"正常遥操没问题"，镜像理论直接被行为证伪。
10-30 那轮"机械镜像（舵盘装反 180°）"的结论**作废**（见文末更正）。

## 根因（main.c `clamp_raw()`，09-02 版引入）

```c
/* 09-02 版（有 bug） */
uint16_t dm = raw_dist_fwd(raw, mn);   /* 只沿 raw 增大方向绕圆算距离 */
uint16_t dx = raw_dist_fwd(raw, mx);
return (dm <= dx) ? mn : mx;
```

`raw_dist_fwd` 是**单向环绕距离**。对 J3 这种**不跨 0 的普通弧**（RAM 限位 76~271°，raw 863→3085）：

- 目标 271.4° = raw 3090，**超出 max 仅 5**；
- 到 max 的正向距离 = 绕整圈 ≈ **4089**（因为 3090 已在 max 前方，要绕一圈才"正向"到达）；
- 到 min 的正向距离 = **1869**（半圈）；
- ⇒ `dm < dx` → 判"min 更近" → **夹到对面的 76°**。

### 完整触发链

```
人手顶死主臂 J3 限位
  → 主臂失力示教、机架柔性，磁编码器挤出 0.4° 超限（271.4 > 软限位 271）
  → teleop.py 原样转发给从臂
  → 从臂 clamp_raw(3090, 863, 3085)：正向距离判据选错侧 → 目标变 863 (76°)
  → 单帧反向 195°， planner/流直接执行 → "反向突变"
```

### 同源旧案与连带影响

- **0924N 旧案**"越限轴自己大幅跑（曾 J3 转 194°）"——同一个 bug 的另一种表现。
- **J5 同样中招**：窗口 180~340，目标 341° 会被打到 180°（此前若出现过 J5"莫名回弹"，即此）。
- 09-02 的修正目标（跨 0/360 包裹弧的禁入区中点选近侧）不受影响：中点到两侧边界必有一侧正向更近，双向化不翻转结果。

## 修复（0924BE）

```c
/* 双向圆周最短距离: 越界点永远夹到圆周上更近的那条边界 */
uint16_t dm  = raw_dist_fwd(raw, mn), dm_r = raw_dist_fwd(mn, raw);
uint16_t dx  = raw_dist_fwd(raw, mx), dx_r = raw_dist_fwd(mx, raw);
uint16_t dmc = (dm <= dm_r) ? dm : dm_r;
uint16_t dxc = (dx <= dx_r) ? dx : dx_r;
return (dmc <= dxc) ? mn : mx;
```

- `clamp_raw()` 修正 → 所有路径（`m`/`a`/流跟随 `#P`/IK/`r` 直写）一并生效。
- `cmdStreamJoints()` 的"被夹掉多少度"统计同步改为圆周最短距离（旧判据在超限场景会算成大半圈）。
- `h` 的 fix 列表增 **`clamp-near-fix`**。

## 对图片 AI 分析的更正

- "从臂 J3 电机/安装方向与主臂相反（dir 应为 -1）"——**不要采纳**。改了 dir=-1 之后 J3 平时遥操就会反向，且 88.6° 与实测 76.1° 的 12.5° 差它无法解释。
- 两臂 `calib_zero_raw`（主 2048 系 / 从全 0 回落 180）与本次现象无关——差值来自钳制 bug，不是零点。
- "主臂 J3 已超软限位 0.4°"这一条观察是对的，正是触发条件；修复后超限目标会被**饱和**在边界而非环绕。

## 对 2026-10-30 文档的更正

`docs/主从J3反向_排查_2026-10-30.md` 结论"机械镜像（舵盘装反 180°）"**作废**。当时快照恰好取自从臂已被钳到对面的状态（J3 顶限位之后），把 bug 造成的稳态差误判成了装配镜像。判别实验（`sf 0` → `a 2 100/250`）不必再做——"正常遥操 J3 跟随正确"这一行为证据已足以排除镜像。
