# 机械臂校准七步操作表（从臂 → 主臂 → 桌面限位 → 休息位）

> **操作入口**：串口控制台 COM11（USART6，115200）。`c` 向导为阻塞式独占，期间网口/CAN/上位机运动指令全部无效。
> **固件要求**：`zf here` 需 0924BW 及以上；`P here` / `P clear` 需 0924CG 及以上。
> **编写日期**：2026-11-13

---

## ⚠️ 三条纪律（先读）

1. **步骤 1~5 必须在同一次上电内一气呵成**：`M a` 永久改写 6 颗舵机的编码基准，中途断电臂处于"零点错乱"状态，只能整个重做。
2. **`M a` / `M <0~5>` 只在人工现场按本流程使用**：这是危险命令，CAN 链路下固件已主动拦截 `cx` 误触（防止首字母兜底掉进校准向导松力矩）。
3. **校准只走串口**：CAN/网口侧最多发只读的 `zi`（看零点）、`L`（看限位）做核对，写入类校准指令禁止从远端链路下发。

---

## 七步操作表

| 步骤 | 指令 | 说明 |
|---|---|---|
| **1 松力矩** | 下发 `t 6 0` | 初始化后松全部 6 轴力矩。⚠ 必须用 `t 6 0`（6=全部六轴）；写成 `t J 0` 时字母 J 会被 atoi 当成轴 0，**只松 J1**——老坑 |
| **2 摆 L 型** | 手动拖动 | 把臂拖到官方 Home 姿态：上臂竖直 / 前臂水平 / 工具朝前，摆正扶稳 |
| **3 中位标定** | 下发 `M a` | 把当前姿态固化为舵机编码器中位 2048。⚠ **永久写入编码基准**，执行后必须立刻接着做步骤 4~5（同一次上电内） |
| **4 校准从臂** | `c` 进入校准 → `0` 记 0 点 → `x` 关节限位校准 → 手转各关节 → `s` → `q` | 必须保持 L 型时下发 `0` 记零点（Phase 1）；然后敲 `x` 进入限位相（Phase 2），手动把每个关节慢慢转到机械两边的限位点，**转满行程**，固件自动记录 MIN/MAX；`s` 存 Flash，`q` 退出 |
| **5 校准主臂** | `c` 进入校准 → `m` → 主臂摆 L 型 → `0` → `s` → `q` | 主臂是虚拟舵机、无力矩概念：无需松力矩、也不校限位，只记零点（供 `fi` 反解用）。`m` 切换校准对象到主臂 |
| **6 桌面限位标定** | `t 6 0` 松力矩 → 爪尖移到桌面最低工作点 → `zf here` → `zf on` | 松力矩手拖到位、扶稳后标定；以当前爪尖实际 FK 高度为桌面 z 下限（实测标定，自动修正 FK 模型 ~10mm 系统性偏差）。自动存 Flash、重启保留，无需手动 save |
| **7 休息位标定** | `t 6 0` 松力矩 → 摆到休息位 → 下发 `P here`（可选 `P clear` 撤销） | 以当前实际位姿作为 `P 0`（折叠/休息位）的新目标；存 Flash 重启保留；存的是相对零点的关节角，之后重做 `M a` / `c` 校准会**随新零点自动重算跟随**；RC CIR 折叠键、折叠位白名单（±3°）、桌面下限推导（未设 `zf` 时）同步生效 |

## `c` 向导按键速查

| 按键 | 作用 |
|---|---|
| `0` | 记录当前校准对象的 6 关节零点 |
| `1`~`6` | 单关节记录零点（微调用） |
| `x` | 切入 Phase 2 限位相（**必须按**；不按 x，手转关节不会记录 MIN/MAX） |
| `p` | 退回 Phase 1 零点相 |
| `m` | 切换校准对象：从臂（存 Flash）→ 主臂（只记零点）→ 双臂对照 |
| `d` | 双臂对照/从臂 间切换（对照模式实时显示两边 raw 差值） |
| `s` | 保存到 Flash |
| `q` | 退出向导 |

## 收尾核对

| 指令 | 核对内容 |
|---|---|
| `L` | 6 关节限位已更新为实测 MIN/MAX |
| `zi` | 零点数据非 0、接近 2048 |
| `zf` | 桌面下限 z 值与刚标定的一致 |

## 相关命令注意

- `P here`：**P 必须大写**，子命令必须写全（`here` / `clear`）——固件在 atoi 前拦截子命令，写错会被当成 `P 0` 预定义位姿而触发运动。
- `P clear`：撤销休息位标定，回编译默认折叠位。
- `zf off`：关闭桌面限位；`zf here` 重标即覆盖旧值。
- `L <J> <min> <max>` 可手动设单关节限位（J=1~6），`L clear` 撤销手动限位。
