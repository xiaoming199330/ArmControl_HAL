# 六轴机械臂性能测试纪要（测试方案）

> 设备：STM32F407ZGT6 + 6×Dynamixel XL320 六轴机械臂
> 平台现状与限制：XL320 消费级舵机，位置分辨率 ≈ 0.29°/step；无激光跟踪仪/外部编码器；
> 测量手段 = 固件 FK 反馈 + 串口读取 + 现有 Python 测试工具。
> 用途：工程验收测试框架 + GB/T 12642 参考指标，二选一使用。

## 二、第 1 层：工程验收测试（现在即可执行，推荐优先）

这一层用 **FK 反馈 + 串口工具**即可完成，指标按本设备实际能力设定（XL320 分辨率约 0.29°）。

### 2.1 接头 / 总线上电自检（冒烟测试）

**目的**：确认硬件链路正常，再进入性能测试。

| # | 步骤 | 命令 | 通过标准 |
|---|------|------|----------|
| 1 | 扫描总线 | `n` | Bus A=3、Bus B=3 |
| 2 | 初始化 | `i` | 无错误打印 |
| 3 | 使能扭矩 | `t a 1` | 6 关节均 OK |
| 4 | 读温度 | `T` | 均 < 55°C |
| 5 | 读状态 | `s` | 6 关节 Moving=No |

### 2.2 单关节到位精度 / 重复性（点到点）

**方法**：对每个关节，指令 `a <J> <deg>`，运动到目标后读取实际角度，重复 N=10 次。
**测量工具**：`alljoint_settle_test.py`（或手动 `p J`）。

### 2.5 运动过程抖动 / 卡顿定性（眼观 + 诊断日志）

**方法**：`P 0` ↔ 前伸往复，观察运动过程是否卡顿/抖动；同时抓固件日志。
**测量工具**：`motion_track.py`、`plan_diag.py`（`d t 1` 看 PLAN 平滑度）。

**方法**：运动中发送 `S` 或触发急停，记录停止响应时间和残差。

## 五、测试纪律与注意事项

1. **先冒烟再性能**：任何测试前先跑 2.1 自检。
2. **关闭串口助手**：否则工具打不开 COM8。
3. **每次改 PID 后记录版本**：用 `F` 保存并记录，避免参数漂移。
4. **安全边界**：测试用点位（P0/前伸/±120mm）都在限位内（J1 40~240, J2 50~210 等），不要超限，避免撞挡块堵转。
5. **运动中串口读取不可靠**：第 2.5 运动抖动项以**眼观 + 固件日志（PLAN/hold）**为准，不要依赖 `p J` 在运动中的值（总线污染）。
6. **重复性测试**：至少要 6~10 次重复，单次不能下结论。
