# 集成板 6 轴单总线（74HC126 保留）— 2026-11-02

> 场景：舵机总线已经做成集成板，板上那片 **74HC126D 焊死拆不下来**，
> 之前 0924AY 的"开漏单总线"路线无法实施。本文给出一条**不动芯片**的单总线方案。
> 固件：**ARM-NET-0924AZ / ARM-BOTH-0924AZ**（`make BUS_ONE=1`）

---

## 1. 先纠正三个前提

| 常见误解 | 事实 |
|---|---|
| "开漏是单总线的前提" | ❌ **不是**。开漏只是"省掉 126"的手段；单总线是拓扑问题，两者正交 |
| "拆不掉 126 就没法单总线" | ❌ 保留 126 一样能做单总线，只需把两路门输出短接 |
| "开漏一定比 126 快" | 只省 **50µs/事务**（两次方向切换的 `for(i<150)` 空转），相对 0.5ms/轴 是 10% 量级 |

**能省的省不掉，能做的照做**：126 留着，6 轴照样并成一条。

---

## 2. 集成板现状（用户实测）

一片 74HC126D 用**两路门**：

| 门 | OE（使能） | A（输入） | Y（输出） | 用途 |
|---|---|---|---|---|
| 门1 | 1OE = **PA8**（DIR_A） | 1A = PB10（USART3_TX） | 1Y → **总线 A** | J1~J3 |
| 门3 | 3OE = **PA10**（DIR_B） | 3A = PC12（UART5_TX） | 3Y → **总线 B** | J4~J6 |
| 门2 | 2OE → GND | 2A → GND | 2Y 悬空 | 闲置（常关断） |
| 门4 | 4OE → GND | 4A → GND | 4Y 悬空 | 闲置（常关断） |

74HC126 是**四路三态缓冲器**，OE 高有效：OE=1 时 Y 输出 = A，OE=0 时 Y 高阻。

---

## 3. 硬件改动：一根线

> **把 1Y 与 3Y 短接**（一个焊点或一根飞线），6 颗舵机就全挂在同一条物理总线上了。

74HC126D（SOIC-14 / DIP-14）引脚号，方便直接落锡：

| 脚 | 名称 | 脚 | 名称 |
|---|---|---|---|
| 1 | 1OE（= PA8） | 8 | **3Y ← 短接点** |
| 2 | 1A（= PB10） | 9 | 3A（= PC12） |
| 3 | **1Y ← 短接点** | 10 | 3OE（= PA10） |
| 4 | 2OE（GND） | 11 | 4Y（悬空） |
| 5 | 2A（GND） | 12 | 4A（GND） |
| 6 | 2Y（悬空） | 13 | 4OE（GND） |
| 7 | GND | 14 | VCC |

⇒ **焊第 3 脚与第 8 脚**。

改完之后的总线拓扑：

```
PB10(USART3_TX) ──> 1A ─[门1]─ 1Y ─┐
                    ↑OE=PA8        │
                                    ├── 同一条总线 ──> 6 颗 STS3215
PC12(UART5_TX)  ──> 3A ─[门3]─ 3Y ─┘
                    ↑OE=PA10
PB11(USART3_RX) ───────────────────┤   （直接挂在总线上，收全部应答）
PD2 (UART5_RX)  ───────────────────┘
```

### 安全性论证（必须成立，否则会烧东西）

> **DIR_A 必须永久保持低电平** ⇒ 门1 永久高阻 ⇒ 只有门3 在驱动总线。

固件侧保证链条：

1. 启动即 `SERVO_SetBusMode(2)` → `JOINT_BUS[0..5]` 全 = `BUS_B`
2. 所有事务走 `DXL_Transmit(BUS_B, ...)` → `DXL_SetDirection(仅动作 DIR_B)`
3. `DIR_A` 停留 `gpio.c` 初始化值 `GPIO_PIN_RESET`（低）
4. `ScanBothBuses()` / `cmdScan()` / `Z` 全量扫描 / `sid` 改 ID —— **全部改成只在 Bus B 上操作**（见 §5）
5. `b` 命令在 `BUS_ONE` 构建下**拒绝 mode 0/1**，从命令层封死

### 可选加固（强烈建议）

`1OE(PA8)` 这根控制线在 PCB 上**割断后接 GND**，让门1 在硬件层面永久关断。
好处：以后无论误烧什么固件，都不可能让门1 与门3 抢总线。
代价：这块板以后只能跑单总线固件（门1 永久失效）。

## 4. 电气影响评估

| 项 | 变化 | 判定 |
|---|---|---|
| TX 驱动能力 | 门3 驱动 6 个舵机输入 + 1m 线 | ✅ 74HC126 输出 ±35mA，足够 |
| 总线上拉 | 原两条各 1kΩ → 并联 **500Ω** | ✅ 上升沿更快；推挽灌电流 6.6mA，安全 |
| Bus A 的 RX（PB11） | 会收到全部总线流量 | ✅ USART3 **未开中断**，只在 DR 里堆积 + ORE 置位，不影响 UART5 |
| Bus A 的 TX（PB10） | 推挽输出但门1 关断 | ✅ 电平到不了总线 |
| 丢读率 | 6 轴串行，轮询周期翻倍 | ⚠ 需实测，见 §7 |

## 5. 固件改动（`BUS_ONE=1`）

| 文件 | 改动 |
|---|---|
| `Makefile` | 新增 `BUS_ONE` 开关；自动置 `BUS_PP=1`；`BUILD_DIR` 加 `_one` 后缀 |
| `main.c` | 新增 `ARM_ONE_BUS_BUILD` 判定宏（`ARM_MASTER_BUILD \|\| BUS_ONE`） |
| `main.c` `ScanBothBuses()` | 单总线时只扫 Bus B 的 ID 1..6（沿用主臂逻辑） |
| `main.c` `cmdScan()` | 输出改为"Bus B 单线，期望 ID 1~6" |
| `main.c` `cmdFullScan()`（`Z`） | 单总线时不扫 Bus A，只扫 Bus B |
| `main.c` `SID_BUS` | 单总线时改 `BUS_A` → **`BUS_B`**（`sid` 改 ID 走 UART5，也顺带改掉提示文本） |
| `main.c` `b` 命令 | `BUS_ONE` 下拒绝 `b 0` / `b 1`，只允许 `b 2` |
| `main.c` 启动 | 钉死 `SERVO_SetBusMode(2)` 并打印 `BUS_ONE: ... DIR_A held LOW` |
| `main.c` 横幅 | tag 升 **0924AZ**，追加 `bus=PP+1Y3Y(1-wire)` |
| `arm_control_api.c` | GET_INFO tag 同步 0924AZ |
| `tools/arm_preflight.py` | 白名单补 `ARM-NET-0924AZ` / `ARM-BOTH-0924AZ` |
| `tools/gen_arm_config_json.py` | tag 表 + 快照行刷新（一次生成落四处） |

## 8. 性能代价（必须知道的取舍）

6 轴串行在同一根线上，一轮读姿态的时间约为双总线的 **2 倍**：

| 配置 | 一轮 6 轴 | 理论采样率 |
|---|---|---|
| 双总线（两条 UART 并行） | 3 轴 × ~0.5ms ≈ 1.5~3ms | 基准 |
| **单总线** | 6 轴 × ~0.5ms ≈ 3~6ms | **约 50%** |

改造前 `GET_STATUS` 实测 4~6ms、采样 52Hz（本来就受丢读影响）。合并后预计 **25~35Hz**：

- RC 遥控（20~40Hz 够用）→ ✅ 可接受
- 轨迹闭环 / 重力补偿（需高频反馈）→ ⚠ 不够，需要重新评估

改造后**连续跑 10 分钟**，重点盯丢读率（改造前 25.5%，J1/J2/J3 承重轴）。
若明显上升，按序处理：**上拉 1k→470Ω → 波特率降到 500kbps → 缩短线束**。

## 9. 红线

| # | 红线 | 后果 |
|---|---|---|
| 1 | **这块板不能再烧双总线固件**（`BUS_ONE=0`） | DIR_A 被拉高 → 门1 与门3 同驱一条线 → 推挽对撞，可能烧 126 或舵机输入级 |
| 2 | 不能在 `BUS_ONE` 固件上执行 `b 0` / `b 1` | 同上（固件已拒绝，不要试图绕过） |
| 3 | 后续改 `sid` 类命令时，`SID_BUS` 必须保持 `BUS_B` | 走 Bus A 既扫不到舵机，又会拉高 DIR_A |
| 4 | 新增任何直接操作 `BUS_A` 的代码前，先确认 `ARM_ONE_BUS_BUILD` 分支 | 同 1 |
| 5 | `drain_echo()` 的"只排 len 个字节、不加等待窗口"逻辑**一行都不能动** | 会重演 0/6 全 MISSING（2026-08-28 实测回归） |
| 6 | 上拉必须是 1kΩ，不能换 4.7k/10k | 1Mbps 下上升沿 τ 超过一个位宽 |

## 11. 一句话总结

**74HC126 拆不掉不影响任何功能**：它只是半双工的方向开关，不是单总线的障碍。
把 **1Y 与 3Y 短接**、固件用 `BUS_ONE=1` 钉死 bus mode 2、`DIR_A` 永久保持低电平，
就能在保留芯片的前提下拿到 6 轴单总线；代价是采样率约减半（25~35Hz），RC 遥控够用，
高频闭环需要重新评估。
