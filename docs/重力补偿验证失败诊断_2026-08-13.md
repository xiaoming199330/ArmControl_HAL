# 重力补偿验证失败诊断（2026-08-13）

## 现象

上位机"验证重力补偿"模块报告 FAIL：

- 目标点：`(180, 0, 100)` mm
- FK 读数：`(182.0, -2.3, 86.5)` mm
- 误差：**13.840 mm**（阈值 2 mm）
- 参数：`gc.k=0.020`、`corr.enabled=1`、`corr.threshold=1°`、`corr.max_rounds=10`

误差主要在 **Z 方向**（实际比目标低约 13.5 mm），说明手臂前伸后被重力压得更竖直。

## 根因分析

### 1. 目标点姿态导致 J2 前倾很大

对 `(180, 0, 100)` 做 IK（使用当前连杆参数 a2~a5）：

| 关节 | IK 解（浮点） |
|---|---|
| J1 | 150.0° |
| **J2** | **193.0°**（前倾 43°） |
| J3 | 160.3° |
| J4 | 172.3° |
| J5 | 206.9° |
| J6 | 17.5° |

J2 前倾 43°，水平伸出距离 r≈180 mm，重力矩很大。

### 2. 重力补偿系数太小

当前 `gc.k=0.02`，J2 前馈补偿量：

```
offset = K * r = 0.02 * 180 ≈ 3.6°
```

但实际需要的补偿可能达到 7° 左右，3.6° 不够。

| K | J2 补偿量 |
|---|---|
| 0.02 | 3.6° |
| 0.03 | 5.4° |
| **0.04** | **7.2°** |
| 0.05 | 9.0° |

### 3. 自适应修正算法有累积 bug（已修复）

原算法：

```c
float corrected = correction_target[j] + error * corr_gain[j];
```

**问题**：当 `error` 减小时，`corrected` 也会减小，导致舵机命令回退。J2 实际位置在 188.5°~189.9° 之间震荡，10 轮后仍差约 4°。

**修复**：改为累积偏移量：

```c
correction_offset[j] += error * corr_gain[j];
float corrected = correction_target[j] + correction_offset[j];
```

仿真对比（假设真实下垂 7°、J2 初始增益 0.5）：

| 方案 | 收敛轮数 | 最终误差 |
|---|---|---|
| 原算法 | 10 轮未收敛 | ~4° |
| 修复后 | 4 轮 | <0.2° |

## 已做的修改

- `Core/Src/main.c`
  - 新增 `correction_offset[6]` 数组
  - `cmdMove()` 中初始化 `correction_offset = 0`
  - 运动到位触发修正时重置 `correction_offset = 0`
  - `'R'` 命令重置时也清零
  - 自适应修正改为累积式，限制 offset 在 ±30°

编译已通过。

## 建议验证步骤

1. **烧录新固件**

2. **加大重力补偿系数**

   ```text
   G 0.04
   ```

   对 `(180, 0, 100)` 这个低位前伸点，0.04 比 0.02 更合适。

3. **可选：加大 J2 自适应初始增益**

   ```text
   A g 2 70
   ```

   把 J2 初始修正增益从 0.5 提到 0.7，收敛更快。

4. **重新执行上位机验证**

   或者手动：

   ```text
   g 180 0 100 0
   # 等"Adaptive correction DONE"出现
   f
   ```

5. **如果仍不达标**

   - 检查电源电压：J2 大负载时总线电压是否掉到 7V 以下
   - 提高 J2 P-Gain：`K 2 48`
   - 检查机械臂零位是否准确，必要时重新标定 a2~a5

## 注意事项

- 重力补偿是**前馈**，只解决"静态下垂"；自适应修正是**关节级闭环反馈**，负责 residual error。
- 累积式修正可能让 J2 的命令角度比 IK 目标大几度，这是正常的——它在补偿重力偏移。
- 上位机阈值 2 mm 对低位大负载点较严，如果机械/电源本身有极限，可适当放宽到 3~5 mm。
