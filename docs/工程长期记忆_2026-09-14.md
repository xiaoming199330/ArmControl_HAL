## 3. 主从臂跟随
- 主臂 `master_service()`：`read_pos_vote` → `servo_to_joint_deg` → 0x13 帧 ≈30Hz；**任一轴读失败整帧不发**；传**逻辑关节角**不传舵机度。协议 `arm_control_protocol.c`（纯逻辑）+ 承载 `arm_proto_serial.c`/`arm_proto_can.c`；帧 `AA 55 seq cmd len payload crc16`。
- **主臂舵机总线**：去 74HC126，6 颗并联 UART5 **开漏单总线**（AF_OD + 1kΩ 上拉 5V）；扫描前 `SERVO_SetBusMode(2)`；**同步写必须按 `JOINT_BUS[]` 分组一次 SyncWrite**（逐轴写 = 机械歪）。扫描/打印/诊断一律分角色（主臂须在 Bus B 扫 `EXPECT_ALL{1..6}`）。
- 安全：raw clamp / 跳变 25°（基准 = 进入流模式那帧读到的**从臂实际位置**，被拒不更新 ⇒ 起始差 >25° **永久拒帧**）/ 桌面+立柱不满足拒整帧 / 断流 >500ms 自动退出。
- 命令：`ms`（rel-home 逻辑角 + 转发统计，**两板各敲一次 = 对拍**）、`lk`(=`1k`/`ik`)、`ma 0/1`（主臂默认 0 只读；`ma 1` 前必须先把 GoalPos 写成当前位置）、`mf 0/1`、`sf 0/1`；**PC 中转**：主臂 `sp <Hz>`（1~100，0=停，吐 `#P` 行）+ 从臂 `#P` 行接收（**成功全静默**，只在坏行/拒帧时限流报错），PC 侧 `tools/pc_relay.py`（`--selftest`/`--list`/`--start`）；清单看 `cmd_registry[]`（`cmdHelp` 硬编码，加命令不必改）。
- 开机：从臂上电 → `sf 0` → 主臂上电 `ms` → 从臂 `lk`/`cn` → 摆齐两臂 → `sf 1`（跳变基准在 `sf 1` 那帧建立）。**两臂上电前摆同一姿态；主臂校准必须拔链路**（上电即 30Hz 外发）。
- CAN 侧复用"上位机/机械臂"寻址：**主臂 = 上位机角色**（`CanProto_SendCmd()` 发 **0x100+node**），**从臂 = 机械臂角色**（收 → NACK 回 0x180+node）；**两端 `node_id` 必须都 = 1**。两个必守：① `AutoRetransmission` **DISABLE**（对端不在时会占死 3 个发送邮箱 ⇒ 拖死主循环）；② 过滤器必须开 **0x100/0x180/0x7E0 三个银行**（只开 0x100 会把从臂回包在硬件层丢掉）。
- CAN 诊断（两角色都有）：**`ct [N]`**（发 N 帧到 0x7E0 做帧计数对拍 ← UART 那轮最缺的）、**`cn`**（hw init/引脚/自检收发/对端回包/`CanProto_RxOkCount` 合法好帧/TEC·REC·LEC **+ MCR/MSR/ESR/TSR 原始值 + `MSR.RX` 引脚实时电平**）、**`cp`**（引脚直流探测，见铁律 9）、**`cy [ms]`**（1ms 采一次 `MSR.RX`，看总线上有没有活动 —— 单向判据、不需对端应答；主臂测前先 `mf 0`）、**`cz`**（发 1 帧的同时高频采 `MSR.RX`，看我方 TX 有没有真的上总线）。
- ⭐ **`ct` 出 `lec=3` + `rec=0`（无人 ACK）时的定位链**：先 `cz`（我方发得出去吗）→ 再 `cy`（对面在不在发帧）→ 再看 `cn` 的 `MSR.RX`（1=隐性空闲 / 0=被拉低）。**不要再拆线重接**，这三条已经把"MCU 侧 / 接线 / 模块供电"分开。判据表见 `docs/主从链路_路线决策_2026-09-14.md` 5.4b。

## 4. 链路排查铁律（UART4 八轮血泪；方法论文档 = 技能 `uart-p2p-link-debug`）
1. `HAL_UART_Transmit` 返回 OK 与线通不通**无关**；"发送计数在涨"不是连通性证据。
2. `stream frames:0` + `rejects` 涨 ≠ 线没通 —— 是收到完整帧但非合法 0x13；看 `NACK sent err=`（1 参数 2 CRC 4 限位 5 急停 7 读失败）。
3. 点对点必须区分请求/响应方向：回包码不拦 → NACK ping-pong 自持死循环，把真故障完全掩盖（已在 `Aproto_Dispatch()` 入口拦 `cmd>=0x80||ACK||NACK`）。
4. 每帧路径上的打印必须节流（`cprint` 阻塞：100 字符 ≈9ms@115200）。**任何高频路径加打印前先问"每秒走多少次"。**
5. `lk` 的 FE/NE/ORE 是真数据：`UART4_IRQHandler` 必须**先读 SR 再读 DR**，顺序反了永远是 0。
6. 判"帧全坏"是软件还是硬件看 `bytes_rx`：正好 = 19×帧数 ⇒ 一个字节不多不少 ⇒ 不是断线/接错/波特率失配，而是**每一位的电气破坏**；`NE≈bytes_rx` = 系统性电气问题。`bytes_rx` 远超实发量 = 对端 RX 根本没收到（悬空/被顶住），不是内容错。
7. **锚点判据：同板自环（同一 MCU/时钟/BRR）必须 100% 正确**；自环都错 ⇒ 只查这一对引脚/这条跳线，别再查协议、共地、地弹、波特率。
8. **单次采样不是测量**：物理上不可能的结果 ⇒ 先怀疑判据/工具，不要编硬件故事；一个相位只用**一个数据源**。连采 8 次打位图（`00000000`/`11111111` 才算稳定，混合 = 节点不稳 ⇒ 拒绝下结论）。同理：`bin8()` 这类格式化助手**不可返回 static 缓冲**（同一次 `cprint` 两个 `%s` 会打出同一个值）。
9. ⭐ **新链路第一次上电，先做"引脚直流探测"再谈总线**（UART 那轮的时间黑洞根因 = 分不清"引脚没接"还是"线不对"）：
   - CAN **`cp`**：RX 脚加内部下拉仍读 `11111111` ⇒ 外面真有驱动 = **收发器已上电且接上了**；`00000000` = 悬空；TX 做推挽输出自检；探完自动恢复。
   - UART：`mp`（引脚直流 + 驱动自检，不需跳线）、`mg`（GPIO 级自环，判跳线用）、`mo A 1 0`+万用表（输出保持找排针，`mo r` 释放）、`ml`（N 帧看 CRC-OK 回环）。这些**全在主臂 ELF**（从臂 0 个）。
10. **诊断隔离**：`ml`/`mg`（跳线）与真链路**不可同时接**；诊断前先用主臂 `ms` 确认 `frames sent` 在涨（否则"没发"被误读成"没收到"）。
11. 换脚位：**不能在 F407 上用 PC10/PC11 走 UART4**（同时是 SDIO_D2/D3，本板有外部上拉）；备选 USART1(PA9/PA10)/USART2(PA2/PA3)，但 `usart.c:9` 称"板上未引出"**无证据**，用前先证实（`mp`/`mo` 一类办法）。
12. "地弹"结论**已作废**（2026-09-14）：两条旧证据都不成立（读失败 ⇒ 整帧不发，不是噪声消失；自环数据是在链路仍插着的污染布置下测的）。
13. **停止条件（满足其一就别"再试一次"，改走菜单式换路线）**：① 同板自环失败；② 故障路径固件已逐行读完且干净；③ 某只脚过不了自己的输出驱动自检。七轮计数器分析的成本远高于两个收发器。

## 5. STS3215（SCS 协议，非 Dynamixel）
- 帧 `FF FF ID Len Inst Params CK`，CK=~(ID+Len+Inst+Params)。
- EEPROM: 5=ID 9/11=Min/MaxAngle 21/22/23=P/D/I 33=Mode(0位置/1恒速/2PWM) 55=Lock；RAM: 40=Torque 41=Accel 42=GoalPos 44=GoalTime 46=GoalSpeed 48=TorqueLimit 56=PresentPos 69=PresentCurrent(≈6.5mA/LSB)。
- **Mode=0 才是位置模式**；EEPROM 写需 Lock=0 + 写完 RESET；置中 = addr40 写 128；速度(46) 1=4.39°/s（**写 0=max**）；加速度(41) 1=100 步/s²（**0=不限制**）。改 ID 用 ESP32 工具（`outputs/sts3215_id_tool`；Signal≈5V，ESP32 侧须串电阻）。

## 7. 上位机接口易错点（全表看 `03_INTERFACE.md`）
- **输入侧统一舵机度**：`a J deg`/`m`/`B`/`q`/`L` 收的都是**舵机度**（旧文档写 `q` 是关节角 = 错）；关节角只在 `f`/`p` 输出行与 `g` 的 pitch。
- **静默钳制**：`m` 每轴硬钳 `0~300`（**无打印**）；`a`/`B`/`q` 按 raw 限位钳制并打印；`L` 把 `min<0→0`/`max>360→360`。
- **默认值**：`m` 省略 `v` 用 `ARM_SC_DEF_VMAX`=**25**（帮助文本与 `arm_params.h:37` 都误写 30）；`B`/`BG` 缺省 30；`sc.def_accel`=**80**；`traj.handoff_deg` 范围 **0~15**。

## 8. 运动与伺服坑（跨场景铁律）
1. **机械行程 ≠ 安全工作区**（9-01 砸桌：堵转拉低电源 → MCU 重启 → Torque OFF 全臂砸桌）。
2. **绝不能用目标值/期望值兜底"读失败"**：`read_pos_retry()` → `read_pos_vote()`（每轴 3 采样，2 个相差 ≤4° 定稿）→ `read_start_pose_checked()`（整组重试 ≤3 轮，仍失败**拒绝运动**，无 fallback）。新增"读位置做安全判定"一律复用，不要裸读 `SERVO_GetPosition()`。
3. "连续稳定 N 秒"判据**不能因读失败清零**（曾致 QL 静默卡死）→ 三态 1=到 / 0=真超差 / 2=读不到，2 时**暂停计时不清零**；"读位置做判定"必须区分"读不到"与"值不对"。
4. 读失败三级诊断 `SERVO_GetPositionDiag()`：`DXL_RD_OK`/`NO_REPLY(查共地)`/`BAD_FRAME(总线噪声)`/`ERROR_BITS`。**别再新增只有一句 "read error" 的报错。**
5. **Bus A(J1/J2/J3) 物理上偶发丢帧，Bus B 从无**（同配置，硬件特性），由重试+表决兜住。
6. 轨迹"提前结束"**必须调 `Trajectory_Stop()`**；只改 `traj_tick` 不清 `traj.active` → 重复交接 + 重复打印。
7. `arm_params[]` 与 `joint_limits` 同存一条 `PID_Record_t`，**表项数固定 24 不得增**（增量 → sizeof 变 → 旧 Flash 记录作废）；要新可调量用编译期常量或升 `PID_FLASH_VERSION`。
8. `SP` 只改 RAM 须 `F` 存盘；`cmdMove()` 开头调 `cmdStreamExit()` 防两套目标互抢。
9. **示教重力补偿定稿 = 混合模式**：J1/J5/J6 必须 Torque OFF 真 free（位置模式抱闸与 PWM duty=0 都有电磁制动，结构性无解），J2/J3/J4 用 PWM 力控；死区自激用 dither+deadband（`teach b=20`）；J3 cap ±40 防损伤共振。
10. "到点剧烈颤抖"已定论 = **J3 PID 被改坏**（`D 3 30`+`Y 3`）；默认 PID = P16(肩 J2=32)/I4/**D12**。**改 PID 前先记基线，`D` 对齿隙大的关节最敏感。**
11. 轨迹收尾 `TRAJ_APPROACH_FRAC=0.05`/`SPEED=30` 为线性斜坡（非阶跃）；`TRAJ_HANDOFF_DEG` 默认 0 关；尾段"顿两下" = 流式微步与舵机内部 planner 交互。
12. 单总线"边发边收" = 控制周期分片：6 轴 GoalPos 批量下发后每 20ms 只允许 1 次读事务（轮转）；**关键是帧长快路径**（SCS 状态帧自带 Length ⇒ 整帧长 4+Length）。**任何新增读操作都不得插进 6 轴同步写之间。**
